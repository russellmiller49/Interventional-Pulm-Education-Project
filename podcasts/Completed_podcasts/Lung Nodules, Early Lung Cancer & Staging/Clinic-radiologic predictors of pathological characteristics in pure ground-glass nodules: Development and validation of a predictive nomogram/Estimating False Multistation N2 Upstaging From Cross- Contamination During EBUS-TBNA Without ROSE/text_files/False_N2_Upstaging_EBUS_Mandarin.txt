InterventionalPulm.com IP Journal Review：无 ROSE 条件下，EBUS 采样不同 N 二站时是否需要更换穿刺针

预计时长：约九分钟

文章类型：原创研究。基于决策分析的蒙特卡洛模拟。

旁白：
欢迎收听 InterventionalPulm.com IP Journal Review。本期我们讨论一个非常具体、但在肺癌分期中很实际的问题：当 EBUS T B N A 过程中没有 ROSE，也就是快速现场评估时，支气管镜医师是否应该在不同 N 二淋巴结站之间常规更换穿刺针，以避免把单站 N 二误判为多站 N 二。

嘉宾：
没错。本期讨论的是 Sagar 及其同事发表在二零二六年 Journal of Bronchology and Interventional Pulmonology 的文章。题目是：Estimating False Multistation N two Upstaging From Cross-Contamination During EBUS T B N A Without ROSE: Insights From a Monte Carlo Analysis。

旁白：
这个问题出现得很及时，因为第九版 T N M 分期把单站 N 二，也就是 N 二 A，和多站 N 二，也就是 N 二 B，区分开来。这个区分有预后意义，也可能有治疗意义。部分单站 N 二患者仍可能进入手术策略的讨论，而多站 N 二通常会使患者远离手术切除路径。

嘉宾：
正是如此。操作层面的担忧其实很直观。如果先穿刺了一个恶性的 N 二淋巴结站，然后用同一根针去穿刺另一个良性的 N 二淋巴结站，前一个站点带来的恶性细胞残留，是否可能造成第二个 N 二站的假阳性？在较早的 T N M 版本里，这可能不会改变整体 N 分期。但现在，N 二 A 和 N 二 B 的差别可能会影响多学科治疗决策。

旁白：
作者对研究目标的界定很谨慎。他们并不是声称要测量 EBUS 中真实的污染率。相反，他们试图估计一个理论上的上限：在一组合理、甚至偏保守的污染假设下，细胞交叉污染究竟有多大概率会转化为假性 N 二 B 分期？同时，为了避免一个假性升期，需要额外更换多少次穿刺针？

嘉宾：
这个框架很重要。这不是前瞻性临床试验，而是一个蒙特卡洛决策分析模型。作者在每个情境中模拟了十万名虚拟患者的纵隔分期过程，场景特别设定为没有 ROSE。患者按照肿瘤位置和临床淋巴结状态分层，包括外周型 c N 零，中央型 c N 零，以及 c N 一疾病。

旁白：
他们还排除了影像或 P E T 已经提示 N 二阳性的患者。对于这个问题来说，这个排除是合理的。如果 N 二疾病本来就已经被怀疑，医师在 N 二区间内的采样策略可能会不同。这里关注的是临床上未被怀疑的隐匿性 N 二疾病，也就是医师在系统分期时，可能会对多个 N 二站采样，却不知道哪一个站点真正是恶性的。

嘉宾：
在基础模型参数中，作者设定外周型 c N 零肿瘤的隐匿性 N 二概率为百分之三，中央型 c N 零为百分之七，c N 一疾病为百分之二十七。在已经存在 N 二疾病的患者中，基础假设是百分之六十为单站 N 二，同时用百分之五十到百分之七十五做敏感性分析。

旁白：
之后，作者加入了采样相关假设。每个站点平均采样三针，范围为两到四针。采样顺序被建模为两种方式。第一种是先采样最不疑似恶性的站点，在这种情况下，恶性站点首先被采样的概率大约只有百分之二十到百分之三十。第二种是随机采样，恶性站点首先被采样的概率接近百分之五十。

嘉宾：
而污染假设是这个模型有意偏保守的地方。作者把每一针的污染概率设为百分之五、百分之十五和百分之二十。百分之十五代表一种中等估计，基于导管或通道污染的相关文献。百分之二十则代表在 EBUS 场景下对细胞学残留风险较高、较保守的解释。

旁白：
文章第一页图一的决策树很有帮助，因为它把逻辑可视化了。以高风险的中央型 c N 零情境为例，隐匿性 N 二疾病从百分之七开始。真正的 N 二疾病再分为单站 N 二 A 和真实多站 N 二 B。只有单站 N 二 A 这组有被假性升期为 N 二 B 的风险。如果恶性站点是后采样的，就没有前一站污染后一站的问题。如果恶性站点先采样，那么每一针的残留污染就会带来第二个站点假阳性的可能。

嘉宾：
这其实就是分母问题。即使从恶性淋巴结采样后的残留污染并不是微不足道，真正处在关键路径上的患者仍然很少。必须同时满足隐匿性 N 二、真实单站 N 二、恶性站点先于良性 N 二站点被采样，并且污染足以造成假性细胞学诊断。每一个分支都会进一步缩小人群。

旁白：
那么结果是什么？

嘉宾：
假性 N 二 B 升期确实可能发生，但并不常见。在中央型 c N 零疾病中，在基础假设下，也就是 N 二患者中百分之六十为 N 二 A，并且每针污染概率约为百分之十五时，使用单根穿刺针会使全部患者中大约百分之零点五到百分之零点八，被错误地从 N 二 A 升期为 N 二 B。

旁白：
那在更高风险情境下呢？

嘉宾：
当 N 二患者中百分之七十五为 N 二 A，并且每针污染概率约为百分之二十时，假性升期率增加到大约百分之一点三到百分之一点七。对于外周型 c N 零肿瘤，假性升期率仍低于百分之零点二。c N 一疾病的风险高于外周型 c N 零，模型估计的假性升期率在百分之零点八到百分之一点四之间。

旁白：
所以核心信息并不是污染完全不重要。更准确地说，模型估计的风险很低，但不是零，而且主要集中在中央型 c N 零和 c N 一疾病中。

嘉宾：
对。第二个结果在实际操作上可能更重要：为了避免一个假性升期，需要额外更换多少次穿刺针？在基础情境下，中央型 c N 零疾病需要大约两百到三百五十次额外换针，才能避免一个假性升期。c N 一疾病大约需要一百到两百次。外周型 c N 零肿瘤则超过一千次。

旁白：
图二把这一点显示得很直观。外周型 c N 零的换针负担非常高，中央型 c N 零较低，c N 一最低，但仍然不算轻。即使在较高风险情境下，每避免一个假性升期所需的穿刺针数量也很少低于一百五十。

嘉宾：
这已经是相当多的针了。而且在没有 ROSE 的环境中，资源限制往往本来就更现实，所以成本、供应、流程负担都不是理论问题。额外操作负担确实需要纳入考虑。

旁白：
敏感性分析也值得注意。作者发现，每针污染概率、N 二病例中单站 N 二的比例，以及采样顺序，对模型结果都有相近的影响。

嘉宾：
这是一点很有用的提醒。答案并不是由某一个神奇变量决定的。更好的 EBUS 特异性污染数据当然会有帮助，但我们也需要更好的流行病学数据，来描述临床隐匿性疾病中 N 二 A 和 N 二 B 的真实分布。同时也需要更好的操作数据，记录 N 二站内真实的采样顺序。

旁白：
我们来做一下批判性解读。主要限制是什么？

嘉宾：
第一，真实的 EBUS 交叉污染风险并不知道。引用的文献提示，在穿刺恶性淋巴结后，针、鞘或通道中可能残留恶性细胞。但这并不等同于证明，之后穿刺一个良性淋巴结就会产生临床上的假阳性恶性诊断。

旁白：
也就是说，残留细胞是这个担忧成立的必要条件，但并不足以证明真的会造成分期迁移。

嘉宾：
完全正确。第二，污染概率的先验假设来自异质性较强的内镜超声文献，可能高估了常规纵隔分期中真实发生的情况。作者也承认，这些是假设性的保守上限。有意思的是，即使在这种保守假设下，假性 N 二 B 率仍然很低。

旁白：
第三，基于 H A L 和 H O M E R 的估计反映的是 N 二或 N 三风险，并不是纯粹的 N 二风险。如果模型中的部分患者实际上是隐匿性 N 三而不是 N 二，那么 N 二站之间交叉污染的相关性可能会更低，也会进一步增加避免一个假性 N 二 B 升期所需的换针次数。

嘉宾：
第四，N 二 A 和 N 二 B 的分布来自病理 N 二数据集，并不一定代表临床隐匿性 N 二人群。作者用敏感性分析处理了这个问题，但这仍然是真实的不确定性。

旁白：
第五，并不是每一次从 N 二 A 到 N 二 B 的假性转换都会改变治疗。现代 N 二治疗决策还包括可切除性、生理储备、诱导治疗反应、机构惯例和多学科判断。如果只有一部分假性 N 二 B 诊断会真正改变治疗，那么为了避免一个真正改变管理的事件，所需换针次数会更高。

嘉宾：
这一点很重要。模型终点是分期迁移，不是治疗迁移，也不是生存或患者中心结局。分期迁移当然重要，但它仍然是一个替代终点。

旁白：
那么，介入肺科医师应该怎样应用这篇文章？

嘉宾：
最站得住脚的解释是风险分层策略。对大多数患者，尤其是外周型 c N 零肿瘤，在每一个 N 二站之间常规换针可能只带来很小的增量获益。这个人群的模型风险几乎可以忽略，而换针效率很低。

旁白：
但文章并没有说，永远不要换针。

嘉宾：
没有。那样解读就过度了。在几个因素同时存在时，选择性换针可能是合理的：没有 ROSE，中央型肿瘤或 c N 一疾病，需要采样多个 N 二站，患者处在手术适应证边界，而且区分 N 二 A 和 N 二 B 很可能会影响肿瘤委员会建议。

旁白：
还有一个不增加成本的流程启示：认真考虑 N 二区间内的采样顺序。作者建模了先采样较不疑似站点的策略，并指出超声特征可能帮助决定先采样哪个 N 二结。先采样外观偏良性的 N 二站，再采样更可疑的 N 二站，可能在不换针的情况下减少污染风险。

嘉宾：
这可能是最实际的要点。换针是一种降低风险的方法。采样顺序也是一种方法。记录也很重要。如果两个 N 二站都是阳性，而第二个站是在第一个明确恶性站点之后采样的，那么这个操作顺序在病理、肿瘤内科、胸外科和放疗科共同解释结果时可能有价值。

旁白：
不过要说清楚，这篇文章不能被用来因为一个 N 二站是第二个被采样的，就否定它的阳性结果。

嘉宾：
绝对不能。一个阳性的淋巴结仍然是阳性的，除非有非常明确的理由质疑它。这个研究提供的是一种概率框架，用来思考罕见的污染相关误分期。它并没有建立一个忽略细胞学结果的规则。

旁白：
未来哪些数据真正能推动这个领域？

嘉宾：
第一步应该是前瞻性的 EBUS 特异性交叉污染研究。比如先采样已知恶性淋巴结，然后在标准化条件下评估穿刺针、针芯、鞘、工作通道，甚至后续良性靶点。但更有临床意义的终点应该是真正的假阳性淋巴结诊断和分期迁移，而不仅仅是检测到残留恶性细胞。

旁白：
操作登记研究也可以帮助回答采样顺序问题：哪个 N 二站先被采样，超声特征如何，做了多少针，是否有 ROSE，最终手术病理或随访是否验证了淋巴结图谱。

嘉宾：
正是如此。这样未来的模型就可以用观察到的概率，来替代保守假设。

旁白：
最后总结一下：Sagar 及其同事讨论了一个非常具体、但在 T N M 第九版区分 N 二 A 和 N 二 B 之后变得更及时的操作问题。他们的蒙特卡洛模型提示，在没有 ROSE 的 EBUS T B N A 中，由穿刺针交叉污染造成的假性多站 N 二升期风险很小，但不是零。风险最高的场景是中央型 c N 零和 c N 一疾病，而在外周型 c N 零疾病中几乎不存在。

嘉宾：
这篇文章的价值并不是要求建立新的普遍换针政策。它给介入肺科医师提供了一种量化思考方式，来处理一个令人担心的分期问题。对大多数没有 ROSE 的病例，在 N 二站之间常规换针可能价值较低；但在预检概率较高、治疗后果较重要的场景下，选择性换针、谨慎安排 N 二采样顺序，以及清楚记录操作流程，都是合理的。

旁白：
今天就到这里。这里是 InterventionalPulm.com IP Journal Review。本期我们讨论的是 Sagar 及其同事关于无 ROSE 条件下，EBUS T B N A 中交叉污染导致假性 N 二 B 升期的蒙特卡洛分析。感谢收听，我们下期再见。
