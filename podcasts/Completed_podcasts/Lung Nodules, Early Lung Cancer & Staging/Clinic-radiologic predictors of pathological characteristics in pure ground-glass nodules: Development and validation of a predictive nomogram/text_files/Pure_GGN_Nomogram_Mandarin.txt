普通话版 T T S 朗读稿

旁白：欢迎收听 Interventional Pulm 点 com，I P Journal Review。在这里，我们聚焦讨论与介入肺病学、胸部肿瘤学和操作决策相关的论文。今天我们讨论的是 Zhu 及其同事发表在二零二六年 Journal of Thoracic and Cardiovascular Surgery 上的一项研究，主题是纯磨玻璃结节病理特征的临床和影像学预测因素。

嘉宾：这篇文章对 I P 听众很有价值，虽然它本身并不是一篇支气管镜论文。纯磨玻璃结节正好处在多个临床流程的交界处：肺癌筛查，结节门诊分诊，机器人支气管镜转诊，胸外科转诊，随访间隔设定，以及患者沟通。这里的临床矛盾大家都很熟悉：有些纯磨玻璃结节是惰性的前驱病变，但有些则是侵袭性腺癌，只是在 C T 上仍然表现为非实性病灶。

旁白：完全正确。这里的核心问题是，常规临床特征和 C T 特征能不能帮助预测的不只是侵袭性，还包括生物学行为，例如 K I 六十七，E G F R 突变状态，以及三级淋巴结构。然后作者又进一步构建了一个用于预测侵袭性腺癌的列线图。

嘉宾：研究设计是回顾性的。他们分析了一千零七十个经手术切除的纯磨玻璃结节，这些结节来自九百九十五名患者。病理结果分为两百二十四个腺体前驱病变，也就是非典型腺瘤样增生或原位腺癌；六百个微浸润性腺癌；以及两百四十六个侵袭性腺癌。主要队列来自仁济医院，外部验证集来自另外四家机构。

旁白：一个重要细节是，这些病灶全部都经过了手术切除。所以从一开始，我们就应该牢记验证偏倚。这不是一个包含筛查项目中发现的所有纯磨玻璃结节的队列。它是一个富集了已经被临床医生认为值得送进手术室的结节的队列。

嘉宾：对，这对临床转化非常重要。如果一个六毫米的纯磨玻璃结节一直在随访，从未被切除，那么它在这个数据集中就是看不见的。因此，这项研究很适合用来关联已切除结节的 C T 表型与手术病理，但它不是所有纯磨玻璃结节的自然史研究。

旁白：影像分析相当细致。他们评估了最大直径，平均直径，C T 最大和平均衰减值，肺实质衰减值，相对和差异密度指标，形状，边界清晰度，空气支气管征，气泡样透亮区，与血管的关系，以及体素异质性。研究使用薄层高分辨率 C T 或超高分辨率靶向扫描。观察者间一致性很强，大小和密度的组内相关系数大约在零点八四到零点九七之间，分类特征的 kappa 值在零点八零到零点九七之间。

嘉宾：影像学上的核心结果是，密度优于大小。为了区分微浸润性腺癌和前驱病变，肺与最大 C T 值比值的 A U C 是零点八二六，最大 C T 值的 A U C 是零点八二零。最大直径的表现较弱，A U C 是零点六三七。他们提出的微浸润性腺癌与前驱病变之间的阈值是：肺与最大 C T 值比值一点六二，最大 C T 值负五百四十八 Hounsfield 单位，最大直径八点六毫米。

旁白：接着，在区分侵袭性腺癌和微浸润性腺癌时，模式仍然相同。肺与最大 C T 值比值的 A U C 是零点八零五，最大 C T 值是零点七九九，最大直径是零点七三八。对应阈值是：肺与最大 C T 值比值一点八九，最大 C T 值负四百五十八 Hounsfield 单位，最大直径十一点五毫米。

嘉宾：这在临床上很符合直觉。随着结节细胞成分增加、含气量减少，衰减值会上升。但作者强调相对密度，这一点很有意思，因为肺实质衰减值会受多种因素影响，例如肺气肿，吸气努力程度，重建方式，以及不同扫描仪之间的差异。相对指标可能可以部分校正这种背景差异。

旁白：而且，在按年龄、性别和吸烟史进行倾向评分匹配之后，影像特征仍然沿着从腺体前驱病变，到微浸润性腺癌，再到侵袭性腺癌的谱系变化：包括大小、密度、形状不规则、边界清楚和体素异质性。这加强了一个观点：这些信号并不只是年龄或人口学因素的反映。

嘉宾：不过，从反方角度看，这些变量放在一起并不算特别隐蔽。一个更大、更密、更不规则、更异质的纯磨玻璃结节更可能是侵袭性的，这并不令人意外。问题是，这项研究能否提供比胸部放射科医生和结节讨论会平时非正式判断更具可操作性的细节。

旁白：这就是列线图的作用。模型使用了四个变量：年龄，最大直径，肺与最大 C T 值比值，以及形状。训练集的 A U C 是零点九二一，内部验证集是零点八八三，外部验证集是零点八九零。校准看起来可以接受，三个数据集的 Brier 分数分别是零点零九三，零点一零二，以及零点一三二。决策曲线分析提示，在较宽的阈值范围内存在净获益。

嘉宾：这是一个不错的模型表现信号。但回顾性外科队列中的模型表现，并不等同于证明使用这个模型能改变结局。对 I P 听众来说，真正的问题是：它是否能帮助判断谁需要持续 C T 随访，谁需要外科评估，以及谁甚至是合理的支气管镜活检候选人。

旁白：纯磨玻璃结节也是很困难的操作目标。即使有机器人支气管镜，锥形束 C T，径向 E B U S，以及器械到达病灶内的确认，一个纯非实性病灶也未必能像实性或部分实性病灶那样提供同等的诊断信心。所以这种模型可能最有用的地方是在更上游，也就是多学科风险分层，而不是作为一个简单的支气管镜触发条件。

嘉宾：生物学相关性也很有意思。在接受驱动基因检测的病灶中，作者报告驱动突变率为百分之七十七，其中 E G F R 突变为百分之六十六。带有 E G F R 突变的纯磨玻璃结节与年龄较大、最大直径较大、最大 C T 值较高、形状不规则和密度异质相关。在多变量分析中，年龄大于五十四岁，最大直径大于十二点五七毫米，以及最大 C T 值高于负四百九十七点八 Hounsfield 单位，是 E G F R 突变的独立预测因素，对应的优势比分别大约是二点一，二点一和二点四。

旁白：这种影像基因组学信号很有启发性，尤其是在多发磨玻璃结节的情境中，因为对每一个病灶都取组织既不可行，也不理想。但我们也要谨慎。E G F R 状态只在一部分病例中可得，队列主要是东亚人群，并且大多是从不吸烟者。这里的目的并不是根据 C T 密度来选择系统治疗，而是在影像风险分层上叠加一种生成假设的生物学信息。

嘉宾：K I 六十七的数据也朝着同一个方向。随着病理侵袭性增加，K I 六十七也升高，并且与不规则形状、空气支气管征和异质性等特征相关。它与年龄、直径和最大 C T 值之间的相关性具有统计学意义，但还没有强到可以让 C T 取代生物学检测。

旁白：三级淋巴结构分析可能是这篇论文最有新意的部分。最大 C T 值与三级淋巴结构计数、三级淋巴结构密度和三级淋巴结构比例相关，而最大直径与三级淋巴结构计数相关，但与标准化后的指标无关。作者提出，较高的衰减值可能不仅反映侵袭性肿瘤成分，也可能反映免疫细胞浸润和三级淋巴结构形成。

嘉宾：这个机制解释很吸引人，但它也是论文中距离即时临床行动最远的一部分。三级淋巴结构在肺癌总体上可能具有预后意义，也可能与免疫治疗反应相关。但在纯磨玻璃结节中，许多病灶在切除后甚至长期随访中结局都很好，目前还不清楚这些信息应该如何改变管理。

旁白：我们来谈谈局限性。第一，研究是回顾性和横断面的。第二，只纳入了手术切除的纯磨玻璃结节，因此良性和未切除结节在很大程度上被排除。第三，研究只使用了一次术前 C T，所以没有捕捉到生长动力学、体积倍增时间，也没有捕捉到实性成分的出现。第四，不同中心的 C T 扫描方案不完全一致，而且模型仍然依赖视觉评估和人工测量。

嘉宾：另外，同一名患者的多个结节被当作独立病灶进行分析。这符合多发磨玻璃结节管理的临床现实，但可能造成统计学依赖。还有，来自四个中心的外部验证是一项优势，但这些中心仍然处在特定的医疗体系和流行病学背景中。

旁白：从临床转化角度看，这篇文章支持对纯磨玻璃结节采取谨慎、影像信息充分的处理方式。一个更大、更密、更不规则、更异质的纯磨玻璃结节，特别是在年龄较大的患者中，即使没有可见的实性成分，也应该更关注侵袭性腺癌的可能性。但这并不自动意味着每一个这样的病灶都需要活检或立即切除。

嘉宾：对。这正是多学科细致判断的重要性所在。对于外周的纯磨玻璃结节，支气管镜的诊断率可能较低，或者结果可能无法诊断；而阴性活检也未必能有意义地降低风险。对一些患者来说，正确路径可能是继续随访。对另一些患者，特别是当病灶增长或密度增加时，转胸外科评估是否进行亚肺叶切除，可能比通过支气管镜追求组织诊断更合理。

旁白：对 I P 项目来说，这篇文章的价值也许在于结节讨论会的语言。与其说，“这是一个纯磨玻璃结节，我们观察吧”，这篇文章推动我们去问：“最大衰减值是多少？相对密度是多少？它是否变得更加异质？形状是否不规则？纵向比较有什么变化？”这会带来更好的讨论。

嘉宾：总结一下：Zhu 及其同事提供了一个大型手术病理数据集，支持 C T 密度，特别是肺与最大 C T 值比值，是纯磨玻璃结节侵袭性的强预测因素。他们的列线图在内部和外部验证中表现良好，而与 E G F R、K I 六十七和三级淋巴结构的生物学关联也很有启发性。

旁白：但是，这项研究不应被理解为一个独立的管理算法。它是一个来自已切除病灶的风险分层工具，而不是一个证明能改善结局的前瞻性试验。对介入肺病医生而言，实际要点是把密度、形态、年龄和生长行为整合进操作分诊，并诚实判断支气管镜什么时候可能真正澄清病情，什么时候只是增加一次无法诊断的绕路。

嘉宾：说得很好。纯磨玻璃结节是一个需要耐心、精准和谦逊的领域。C T 能告诉我们很多，但不是全部。有时候，最好的干预，是选择正确的时机不去干预。

旁白：本期 Interventional Pulm 点 com，I P Journal Review 到这里就结束了。感谢收听。下次我们将继续带来另一场聚焦证据、影像和介入肺病学交汇处的讨论。
