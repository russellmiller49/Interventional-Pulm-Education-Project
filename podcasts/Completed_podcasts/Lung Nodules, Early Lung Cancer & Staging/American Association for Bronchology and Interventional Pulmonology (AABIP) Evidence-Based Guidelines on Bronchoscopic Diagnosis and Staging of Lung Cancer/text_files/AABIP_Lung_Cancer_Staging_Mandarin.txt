InterventionalPulm.com IP Journal Review：AABIP 关于肺癌支气管镜诊断与分期的指南

预计时长：9 到 10 分钟

文章类型：临床指南与共识声明

旁白：欢迎收听 InterventionalPulm 点 com IP Journal Review。今天我们讨论 Miller 及其同事在 2025 年发表于 Journal of Bronchology and Interventional Pulmonology 的文章：AABIP 关于肺癌支气管镜诊断与分期的循证指南。

嘉宾：这对介入呼吸病学听众来说是一篇很重要的文章。不是因为每一条建议都有完美的随机试验数据支持，事实并非如此；而是因为它试图把几个日常程序性决策整理清楚：外周结节该做支气管镜还是 C T 引导经胸针吸活检；取样时该用几种工具；快速现场细胞学评估是否有价值；EBUS 纵隔分期应该做到多系统；以及什么时候可以合理避免额外的侵入性分期。

旁白：对。它的范围主要包括两个领域：外周肺结节的非手术活检，以及在疑似或确诊肺癌中使用凸探头 EBUS 进行纵隔分期。方法学上，工作组采用了改良 Delphi 流程，系统检索文献到 2023 年 3 月，使用 GRADE 评估证据确定性，并用 NICE 风格的语言表达每条建议的强度。

嘉宾：这一点很重要，因为“考虑使用”、“使用”、“不常规提供”和“无法提出建议”并不是同一个意思。这不是一份说“每个病例都只有一种正确做法”的文件。它更有层次。六条建议由荟萃分析支持，三条由系统综述支持，而且很多证据的确定性是低或非常低。

旁白：我们先从最可能引起关注的核心建议开始：对于未定性的外周肺结节，外周导航支气管镜与 C T 引导经胸针吸活检应该如何选择。

嘉宾：指南建议，评估未定性外周肺结节时，可以考虑外周导航支气管镜活检，而不是 C T 引导经胸针吸活检，但要同时考虑患者因素、结节特点、当地技术经验和成本。这里的措辞很关键。它说的是“考虑”。它并没有说支气管镜的诊断率明显更高。

旁白：事实上，较早的比较性数据在诊断率上更支持 C T 引导经胸活检。荟萃分析显示，经胸活检的诊断率为 87%，外周导航支气管镜为 67%，优势比为 3.24，支持经胸活检。但是，经胸活检的气胸发生率明显更高，合并风险差为 0.18。

嘉宾：这就是整个权衡的核心。C T 引导经胸活检历来是高诊断率检查，但并发症谱不同。支气管镜可能带来更低的气胸风险，而且可以在同一次麻醉事件中进行纵隔分期，甚至对多个靶点取样。

旁白：随后指南也承认了一个技术问题：许多证据基础来自更早期的支气管镜平台。

嘉宾：正是这样。VERITAS 试验比较了电磁导航支气管镜加数字断层合成，与 C T 引导经胸针吸活检。虽然这个研究发表在正式检索截止之后，指南仍将其作为高影响力研究进行讨论。VERITAS 中，电磁导航支气管镜的诊断率为 79%，经胸活检为 73.6%；需要干预的气胸在经胸活检组为 11.5%，在支气管镜组为 0.8%。但是，当 VERITAS 被纳入更广泛分析后，经胸活检总体合并诊断率仍然更高，只是差距缩小了。

旁白：所以，唱反调的问题是：这条建议主要是由证据驱动，还是在预判技术发展的方向？

嘉宾：两者都有一点。正式证据在许多早期比较中仍然显示 C T 引导活检的诊断率更高。但在真实的介入呼吸决策中，相关的比较对象不一定是 2011 年的径向 EBUS。现实中的比较对象可能是机器人支气管镜、锥形束 C T、数字断层合成、增强透视、冷冻活检、更好的针具、更好的 C T 到身体偏差管理，以及一个可能在同一场操作中完成纵隔分期的团队。

旁白：因此，实际信息不是“所有人都做支气管镜”。而是要根据病灶大小、支气管征、肺气肿、离胸膜的距离、是否需要淋巴结分期、抗凝问题、当地成功率，以及患者对气胸风险的具体耐受度来选择路径。

嘉宾：当地数据很重要。每个项目都应该了解自己的诊断率和并发症率。一个高量 C T 活检服务和一个低量支气管镜项目，不应该用同样的方式解读这条建议；一个拥有锥形束 C T、成熟细胞病理支持、并且机器人支气管镜量很高的项目，又是另一种情况。

旁白：第二条建议更偏操作层面：在支气管镜评估未定性外周结节时，考虑使用多种活检工具，而不是单一工具。

嘉宾：这很符合许多介入呼吸团队已经在做的事情。荟萃分析包括十项研究，发现增加工具后诊断率从大约 63% 提高到 73%，绝对提高约 10%，优势比为 1.78。

旁白：亚组分析仍然支持多工具策略。传统工具的优势比为 1.64；冷冻活检亚组的优势比为 2.06，支持联合工具优于单一工具。

嘉宾：但“多工具”不应该意味着随机堆工具。工具要匹配病灶。如果病灶贴近气道，经支气管针吸或冷冻活检可能更有价值。如果工具在径向 EBUS 图像中处于偏心位置，钳夹活检可能不那么可靠。如果需要分子检测，标本处理和组织结构就很重要。所以这条建议支持的是有思路的多工具策略，而不是程序性自助餐。

旁白：第三条建议讨论外周结节中的快速现场细胞学评估，也就是 ROSE。指南说，可根据当地资源和临床背景考虑使用。

嘉宾：数字很有意思。六项研究、超过 2,700 名患者显示，使用快速现场细胞学评估可以提高诊断率，优势比为 2.71。在随机试验亚组中，优势比为 1.93。操作时间没有显著差异，平均差约为负 1 分钟，不过异质性很高。

旁白：这挑战了一个常见担忧：快速现场评估一定会拖慢整个房间流程。

嘉宾：是的，但要加上限制。所有纳入研究都来自亚洲中心。而在有锥形束 C T 或数字断层合成进行实时“工具在病灶内”确认时，快速现场细胞学评估的增量价值可能会改变。它能确认细胞量是否足够，但不一定确认取到了肿瘤中最有生物学代表性的部分。它还需要细胞学人员、远程细胞学基础设施，或者未来某种人工智能辅助流程。

旁白：所以在实施上，它可能最适合组织量稀缺、重复活检风险高、需要分流标本做培养或分子检测，或者中心有可靠细胞病理支持的情境。

嘉宾：对。但没有快速现场细胞学评估的中心，不应该把这解读为高级支气管镜就不成立。它意味着团队需要补偿策略：更有目的地选择工具，保证足够的取样次数，提前规划细胞块，条件允许时做触片，并与病理密切协作。

旁白：第四条建议是有意保持开放：对于恶性外周结节，指南无法就使用外周支气管镜还是 C T 引导经胸针吸活检来专门获得分子分析组织提出建议。

嘉宾：这个荟萃分析很小，只有三项研究、357 名患者。结果没有显著差异，优势比为 1.72，置信区间非常宽，从 0.07 到 45.05。两组分子检测组织充分率都超过 90%，但证据确定性非常低。

旁白：这里有一个关键的分母问题：这些结果适用于已经获得恶性诊断之后的样本。

嘉宾：完全正确。阳性活检中用于下一代测序的充分率，和整个诊断路径并不是一回事。C T 引导经胸活检可能获得更大的组织条，但支气管镜可能把诊断和分期合并完成。组织是否足够取决于肿瘤细胞量、坏死、针径、取样次数、固定方式、免疫组化使用是否节制，以及操作者和病理团队是否配合良好。

旁白：接下来转向分期。第五条建议是最清楚的建议之一：在进行凸探头 EBUS 纵隔分期时，使用系统性分期检查，而不是只取样影像学可疑淋巴结。

嘉宾：这可能是指南中最能定义实践的一部分。文件描述了不同层级的分期彻底程度：从靶向取样，到最低标准的系统性分期，到更全面的检查，再到结合 EUS 或 EUS-B 的完整系统性分期。

旁白：系统性方法比单纯靶向取样多发现大约 5% 到 15% 的隐匿性 N 二或 N 三疾病。

嘉宾：这很重要，因为影像学正常的纵隔并不总是病理学正常。文件描述的最低标准，是按照 N 三到 N 二再到 N 一的顺序，对核心纵隔链进行取样；在合适情况下包括 4 R、4 L 和 7 等关键站位；重点关注 EBUS 下短轴至少 5 毫米，或 PET 阳性的淋巴结。

旁白：指南还纳入了第九版 T N M 分期的影响，尤其是区分单站 N 二与多站 N 二疾病。

嘉宾：这是一个重要概念变化。如果因为快速现场评估已经显示第一个 N 二淋巴结阳性，就停止操作，那么对于现代预后判断和治疗规划来说，分期可能是不完整的。问题不再只是“有没有 N 二疾病”，而是“有多少 N 二疾病，累及几个站位”。

旁白：唱反调的问题是：系统性 EBUS 需要时间、培训和镇静。它在所有地方都可行吗？

嘉宾：并不一样可行。这就是记录很重要的地方。如果操作者做的是靶向分期，报告应该写清楚。如果做的是系统性检查，报告应该记录检查了哪些站位、取样了哪些站位、大小、超声特征、取样次数和标本充分性。指南不会凭空创造培训条件，但它提高了我们说“分期 EBUS”时应当达到的标准。

旁白：第六条建议说，对于有隐匿性 N 二或 N 三风险因素、但没有明确影像学纵隔受累的患者，如果凸探头 EBUS 分期为阴性，不应常规提供术前纵隔镜检查。

嘉宾：三项研究的合并分析显示，EBUS 单独策略与 EBUS 加纵隔镜策略之间，在漏诊 N 二或 N 三疾病方面没有统计学显著差异，风险差为 0.03，置信区间跨过零。在 Bousema 随机试验中，即刻手术组的意外 N 二疾病为 8.8%，确认性纵隔镜组为 7.7%。

旁白：所以纵隔镜并没有消失，但在高质量系统性 EBUS 阴性之后，常规确认性纵隔镜越来越难以证明必要。

嘉宾：对。它仍然有角色，尤其是在影像和病理不一致时，比如一个很大、F D G 摄取很强的淋巴结，EBUS 取样却阴性或不充分；或者 EBUS 检查本身不完整。但对很多患者来说，进入手术切除并进行术中淋巴结清扫是合理的。

旁白：第七条建议讨论肿瘤大小。即使肺门和纵隔影像学正常，超过 3 厘米的原发肿瘤也应被视为隐匿性纵隔转移的风险因素。

嘉宾：四项回顾性研究、超过 1,200 名患者显示，超过 3 厘米的肿瘤发生隐匿性 N 二疾病的风险更高，合并风险差为 0.06。指南把这作为风险分层，而不是僵硬的命令。

旁白：所以，一个 3.4 厘米的外周腺癌，即使 PET 淋巴结阴性，也不是和一个 1.4 厘米的外周纯磨玻璃病灶同样的分期问题。

嘉宾：正是如此。这也直接引出第八条建议：对于纯磨玻璃结节，并且 C T 和 PET 显示纵隔正常的患者，不应常规提供侵入性纵隔分期。

旁白：回顾性文献显示，纯磨玻璃结节的淋巴结转移几乎没有或完全没有，大约为 0 到 1%。部分实性结节风险更高，尤其是实性成分与整体肿瘤的比例超过 0.5 时。

嘉宾：这对避免过度分期很有帮助。如果病灶确实是纯磨玻璃，薄层 C T 确认这一点，PET 和 C T 没有淋巴结疑点，临床表现也符合惰性腺癌谱系病变，那么侵入性纵隔分期很可能没有帮助。但“确实”两个字很重要。测量质量和放射学术语都很关键。

旁白：最后是第九条建议：对于早期非小细胞肺癌患者，如果没有其他侵入性分期指征，指南无法就是否常规使用凸探头 EBUS，在立体定向放疗前寻找隐匿性 N 一疾病提出建议。

嘉宾：这是一个很有意思的灰区。立体定向放疗前做 EBUS 的理由是：手术患者通常有病理淋巴结评估，而接受立体定向放疗的患者通常没有。隐匿性 N 一疾病可能导致区域失败。但在影像学淋巴结阴性的立体定向放疗队列中，侵入性淋巴结分期并没有显示出一致的生存或复发获益。

旁白：有些研究发现，凸探头 EBUS 将大约 2% 到 5% 的临床 N 零患者上调为 N 一，但 EBUS 也可能漏掉叶内淋巴结，也就是 12、13、14 站，这些通常超出标准 EBUS 的可及范围。

嘉宾：而且很多接受立体定向放疗的患者本身医学上不可手术，或风险很高。所以即使发现显微 N 一疾病，也不一定能以改善结局的方式改变管理。指南在这里没有过度解释，这是合理的。

旁白：我们最后谈谈局限性和实施。作者很明确地指出，很多证据是回顾性、观察性的，并且受到快速技术演进的影响。

嘉宾：诊断率这一点尤其重要。不同支气管镜研究对诊断率和准确率的定义并不一致。文章指出，取决于使用严格、中间还是宽松定义，报告的诊断率可以相差超过 20%。这应该提醒大家，在不同平台或不同论文之间比较单一数字时要非常谨慎。

旁白：还有资源假设。系统性 EBUS 需要培训。快速现场细胞学评估需要细胞病理或远程细胞学。高级外周支气管镜可能需要机器人平台、锥形束 C T、数字断层合成、麻醉支持和足够的操作量。这些建议在三级或四级中心可能更容易落地，在资源较少的环境中则不一定。

嘉宾：另外，因为这是一份 AABIP 关于支气管镜诊断和分期的指南，读者也应注意专业视角和技术背景。这并不削弱文件的价值，但让推荐措辞变得更加重要。最强的信息并不是“支气管镜取代一切”。而是诊断和分期路径应该整合、根据风险调整，并且要对当地结果负责。

旁白：那么，这篇文章到底增加了什么？

嘉宾：它给介入呼吸临床医生提供了一个结构化框架。对于外周结节，支气管镜正在变得越来越有竞争力，尤其是在低气胸风险和联合分期重要的时候；但诊断率仍然高度依赖技术和经验。多工具通常能提高诊断率。快速现场细胞学评估可以有帮助，但实施取决于资源。只要活检能够诊断，支气管镜和经胸路径似乎都可以获得足够的分子检测组织。

旁白：那分期方面呢？

嘉宾：当需要纵隔分期时，系统性凸探头 EBUS 应该成为默认概念。高质量阴性 EBUS 后，常规确认性纵隔镜通常没有必要。肿瘤超过 3 厘米时，即使影像正常，也应推动临床医生考虑侵入性分期。纯磨玻璃结节且纵隔正常者，通常不需要侵入性分期。至于仅为了在立体定向放疗前寻找隐匿性 N 一疾病而常规做 EBUS，目前仍未解决。

旁白：这是很好的总结。实际应用的角度可能是：用这份指南来标准化决策，但不要让它取代程序判断、当地结果数据、多学科讨论，或患者特异性的风险评估。

嘉宾：没错。这是一张路线图，不是自动驾驶。在肺癌诊断和分期中，自动驾驶往往就是导致做得太多或做得太少的原因。

旁白：本期 InterventionalPulm.com IP Journal Review 到这里结束。感谢收听。
