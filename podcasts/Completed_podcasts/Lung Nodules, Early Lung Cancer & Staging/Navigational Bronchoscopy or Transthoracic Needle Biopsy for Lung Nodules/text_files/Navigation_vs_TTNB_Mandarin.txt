旁白：欢迎收听 Interventional Pulm 点 com 的介入肺脏病文献回顾。本期我们讨论一项针对外周肺结节的头对头比较：导航支气管镜与经胸针吸活检。研究是 VERITAS 试验，第一作者是 Lentz，二零二五年发表于 New England Journal of Medicine。

嘉宾：是的。这是一项由研究者发起的、多中心、随机、非劣效试验，比较导航支气管镜与 CT 引导下经胸针吸活检，也就是 T T N B，用于外周肺结节患者。结节大小为十到三十毫米，入组患者的癌症预测概率为中等到较高。

旁白：这里的技术也很重要。支气管镜组使用了电磁导航，并结合数字断层合成技术，具体来说是 Medtronic 的 Illumisite 平台。试验包括美国七个中心，既有学术中心，也有社区医疗机构。考虑结果的可推广性时，这一点很重要。

嘉宾：主要结局是十二个月时的诊断准确性。它的定义是获得一个具体诊断，也就是恶性诊断，或一个具体的良性诊断，并且在一年随访后被确认是准确的。非劣效界值是十个百分点。

旁白：我们直接来看主要结局。他们发现了什么？

嘉宾：导航支气管镜达到了非劣效终点。支气管镜组的诊断准确性为百分之七十九点零，也就是一百一十九名患者中的九十四名。T T N B 组为百分之七十三点六，也就是一百一十名患者中的八十一名。绝对差异为五点四个百分点，百分之九十五置信区间从负六点五到十七点二。非劣效检验的 P 值为零点零零三。

旁白：也就是说，从统计学上讲，它是非劣效的。点估计实际上偏向导航支气管镜，尽管没有达到优效性，优效性检验的 P 值为零点一七。这在临床上很有意思，但仍然应该解释为一个非劣效结果。

嘉宾：完全正确。诊断得率是一个次要结局，更聚焦于操作本身，而不包括十二个月确认这个部分。这个指标也非常接近：导航支气管镜为百分之七十九点三，T T N B 为百分之七十七点九。

旁白：安全性特点，是临床讨论中尤其重要的部分。

嘉宾：绝对是。导航支气管镜组的总体并发症发生率为百分之五点零，而 T T N B 组为百分之二十九点二，主要由气胸驱动。任何气胸在支气管镜患者中发生率为百分之三点三，而在 T T N B 患者中为百分之二十八点三。需要干预的气胸，也就是需要胸管或住院的气胸，在支气管镜组为百分之零点八，基本上是一名患者，而 T T N B 组为百分之十一点五。

旁白：这个绝对差异很难忽视。与导航支气管镜相比，T T N B 导致一例需要干预的气胸的伤害所需人数，大约是九到十。这并不自动意味着它会改变所有临床实践，但如果这个估计在更广泛的实践环境中仍然成立，那么它是一个具有临床意义的安全性信号。

嘉宾：是的。研究方法也有助于解释结果。他们对影像进行了中央审核，以确认结节适合两种技术。这一点很重要，因为在常规临床实践中，病灶选择通常决定患者会被转向支气管镜，还是经皮活检。

旁白：他们筛查了五百一十九名患者，最终随机分组二百八十八名。因此，这并不是一个所有外周肺结节患者都包括在内的人群。一个关键排除标准是技术上不可行：中央审核后，十九名患者被认为不适合 T T N B，一名患者被认为不适合导航支气管镜。这意味着，本试验适用于专家认为两种方法在技术上都可行的结节。

嘉宾：完全正确。这是一个重要的临床边界。这些结果不应推广到每一个八毫米的胸膜下病灶，也不应推广到每一个没有气道通路的病灶，或者每一个解剖结构明显更适合某一种方法的患者。

旁白：我们来谈谈 T T N B 组。百分之七十三点六的诊断准确性，和历史研究中经常接近百分之九十的数字相比，可能感觉偏低。

嘉宾：作者也讨论了这一点。他们认为，许多更高的估计来自回顾性、非随机研究，偏倚风险更高。本试验中结节中位大小为十五毫米，而目标越小，T T N B 的表现越差。因此，如果关注病灶大小以及结局定义的严谨程度，T T N B 的结果可能并不那么令人意外。

旁白：但是有一个重要的混杂因素：R O S E，也就是快速现场评估。支气管镜病例中，百分之九十五点八使用了快速现场评估，但 T T N B 病例中只有百分之七点二使用。这个差异会不会解释一部分支气管镜的表现？

嘉宾：有可能。影响的大小不确定，但这个不平衡很明显。它可能反映真实世界的实践模式，但它也让我们很难说，这项研究是在孤立地比较设备或取样路径。一个常规配备细胞病理支持的 T T N B 项目，表现可能会不同。

旁白：随机分组后的脱落也值得注意。分到 T T N B 组的患者中，有十六名没有接受该干预，而导航支气管镜组为八名。在 T T N B 组中，有六例即使经过中央可行性判定后，仍被归因为操作医生拒绝。

嘉宾：这是一个很有启发性的流程细节。它提示我们，有些病灶在中央审核中可能被认为技术上可行，但在床旁或 CT 机旁的实际操作中，操作医生仍然会感到不放心。此外，十名 T T N B 患者在操作当天的术前影像上出现了病灶缩小，而支气管镜组只有两名。作者把这种情况计入主要分析中的诊断结局，并认为这可能使分析偏向 T T N B，因此反而加强了支气管镜非劣效的结论。

旁白：现在来问一个唱反调的问题。研究由 Medtronic 资助，而且所有支气管镜都使用 Illumisite 平台。作者说明，资助方没有参与试验设计、数据分析或论文写作。但支气管镜组使用单一平台，仍然会影响我们对结果的解读。

嘉宾：确实会。这不是把所有先进支气管镜平台与 T T N B 进行比较。它比较的是一种现代化的电磁导航和数字断层合成工作流程，由经验丰富的操作者使用，对照的是参与中心的 CT 引导 T T N B。在某些系统中，这可能正是临床相关的比较，但它不是一个适用于所有技术平台的普遍性结论。

旁白：操作者经验也是另一个关键点。支气管镜组可能反映的是一个成熟、高表现的先进支气管镜环境。问题是，低操作量的医生、项目学习曲线早期，或者缺乏稳定 R O S E 支持的情况下，能否复制类似的准确性和安全性。

嘉宾：完全正确。同时，CT 引导活检是一项成熟技术。也可以这样说，如果一种成熟的经皮技术在随机试验中有明显更高的气胸发生率，那么即使支气管镜组代表的是有经验的实践环境，这个安全性差异仍然具有临床意义。

旁白：亚组数据也很有用。支气管征重要吗？

嘉宾：重要。在有支气管征的患者中，导航支气管镜的诊断准确性为百分之九十点二，T T N B 为百分之七十五点七，绝对差异接近十五个百分点，偏向支气管镜。在没有支气管征的结节中，数字几乎相同：百分之七十三点一和百分之七十二点六。

旁白：这支持了一个生物学和操作上的直觉：通向病灶的气道路径很重要。对于有支气管征的结节，这些数据有力支持认真考虑把导航支气管镜作为一线策略，尤其是在较低气胸风险也参与决策的时候。

嘉宾：对于小于十五毫米的结节，两种策略的准确性都有限：导航支气管镜为百分之六十九点六，T T N B 为百分之六十六点一。对于十五到三十毫米的结节，导航支气管镜为百分之八十七点三，T T N B 为百分之八十一点五。这进一步强调，病灶大小仍然是诊断规划的核心因素。

旁白：那么，介入肺脏病听众应该如何应用这项研究？这项研究支持一种支气管镜优先策略，用于经过选择的十到三十毫米结节，这些结节对两种方法在技术上都可行。尤其是在存在支气管征，并且支气管镜能够由经验丰富的团队完成，同时具备适当影像和细胞病理支持的情况下。

嘉宾：但是限制仍然存在：平台特异性、操作者经验、支气管镜组几乎普遍使用 R O S E，以及入组病灶的选择性。说每一个外周结节都应该先做支气管镜，这个说法太宽泛。更好的解释是，对于解剖上合适的结节，在有能力的项目中，导航支气管镜可以提供类似的、经过确认的诊断准确性，同时显著减少需要干预的气胸。

旁白：这是一个很实用的信息。它把操作前的讨论，从默认认为 T T N B 总是更准确，转向更细致的讨论：病灶解剖、支气管征、当地经验、可用的导航技术、细胞病理工作流程，以及气胸风险。

嘉宾：同意。这项试验给介入肺脏病社区提供了一个有力的随机数据点，可用于患者选择和多学科结节规划。它并没有消除 T T N B 的作用，但它确实支持这样一种观点：先进支气管镜应该更早被考虑，而不是只在经皮活检被认为风险太高，或者已经失败之后才被考虑。

旁白：本期 Interventional Pulm 点 com 介入肺脏病文献回顾到这里就结束了。核心信息是，VERITAS 支持导航支气管镜作为一种对选定外周结节非常有竞争力的诊断策略，在气胸风险方面具有重要安全优势，同时仍然留下关于平台可推广性、R O S E 和操作者经验的重要问题。感谢收听。
