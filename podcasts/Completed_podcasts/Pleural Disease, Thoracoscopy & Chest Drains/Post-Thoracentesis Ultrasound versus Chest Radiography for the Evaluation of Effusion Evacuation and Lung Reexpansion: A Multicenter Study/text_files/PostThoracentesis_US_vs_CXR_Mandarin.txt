旁白：欢迎收听 InterventionalPulm.com IP Journal Review。本期节目我们讨论 Ratwani 及其同事发表在二零二五年 Annals of the American Thoracic Society 上的一项研究，主题是胸腔穿刺抽液后超声与胸部 X 光在评估胸腔积液排空和肺复张方面的比较。资深作者是 Shojaee，这项研究简称 E V A C U T E。

嘉宾：这是一个非常务实的流程问题。治疗性胸腔穿刺抽液之后，临床医生通常想知道几个问题：胸膜腔是否已经充分排空，肺是否已经复张，以及是否有并发症的证据。指南已经不再建议对无症状患者常规进行术后胸部 X 光检查，但许多临床流程仍然默认安排胸片。

旁白：研究者纳入了一百四十七名患者，并分析了一百四十五名因大量游离性胸腔积液接受治疗性胸腔穿刺抽液的患者。研究在六个学术中心进行。患者中位年龄为六十四岁，最常见的已知病因是恶性肿瘤，约占百分之五十。

嘉宾：主要比较项目是胸腔穿刺抽液后超声与胸部 X 光在判断胸膜腔完全排空方面的一致性。他们的定义很严格：超声的前方、腋中线和后方三个切面均看不到液体，同时胸部 X 光上没有肋膈角变钝。

旁白：结果显示一致性非常高。研究者使用 Gwet 的 A C 一来处理 kappa 悖论。对于完全排空这一结局，系数为零点九三，百分之九十五置信区间为零点八三到一点零零。

嘉宾：这是一个很强的一致性统计结果。他们还评估了残余积液的大小，把残余液体分为少量或大量。在这个方面，一致性仍然相当好，kappa 值为零点六四。

旁白：他们还讨论了受困肺。受困肺这个概念在临床上总是比单纯的影像标签更复杂。他们采用了务实定义，把胸痛或难以控制的咳嗽等症状，与肺复张不完全结合起来判断。

嘉宾：操作者基于超声做出的评估，与基于胸部 X 光做出的评估之间一致性很强，kappa 值为零点八九。根据超声和临床体征，操作者在百分之四十九点七的病例中判断为受困肺；查看胸部 X 光之后，这个比例只轻微变化到百分之四十七点六。

旁白：这提示，至少在这个人群中，并且在有经验的操作者手中，对于这个特定床旁问题，胸部 X 光可能增加的信息有限。但这里有一个重要的偏倚问题。

嘉宾：是的。操作者并没有被盲法处理。评估顺序是先做超声，然后再看胸部 X 光。这反映了真实临床流程，但也意味着，操作者对 X 光的解读可能受到他刚刚在操作过程中看到和经历的内容影响。

旁白：所以，受困肺方面的一致性是务实的一致性，而不是两个完全独立影像模式之间的纯粹比较。作者通过使用盲法独立评审来加强研究的其他部分。两名肺科医生评估超声，两名放射科医生评估胸部 X 光，用于判断观察者间可靠性。

嘉宾：而且，对于完全排空这一结局，操作者与盲法超声评审之间的一致性也很强，kappa 值为零点八一。这支持床旁超声在判断排空终点方面具有可靠性。

旁白：现在来问一个反方问题：超声在哪些方面评估得不那么好？

嘉宾：肺实质异常。对于肺不张，一致性明显较弱，Gwet 的 A C 一为零点二一；对于肺实变，A C 一为零点一三。胸膜增厚的一致性很高，为零点八九，这很合理。但胸部 X 光仍然可能提供更广泛的肺实质概览。

旁白：气胸相关结果也很难解读。整个队列中只有六例气胸，而且没有一例需要干预。超声与胸部 X 光在气胸检出方面的一致性为轻度到中等，kappa 值为零点三零。即使两名放射科医生彼此之间的一致性也只有中等，kappa 值为零点四七。

嘉宾：六例气胸中有三例在超声上可见，但在初始胸部 X 光上没有看到。这可能提示，在专家手中超声具有较高敏感性，但由于总共只有六个事件，这项研究没有足够统计效能来评估气胸检出。真正的主要信息还是关于积液排空和肺复张。

旁白：下一个问题是结果能否推广。研究中的操作者来自六个学术中心，均为有经验的操作者。术后超声检查的中位时间刚刚超过两分半钟。这很高效，但前提是操作者具备超声技能，并且使用标准化扫描模式。

嘉宾：完全正确。这些结果不能自动推广到低操作量的医生，也不能自动推广到缺乏强有力超声培训的环境。一个关键的实施问题是图像存储。胸部 X 光会自动归档到 P A C S 系统。超声图像是否会保存、标记，并且能否在电子病历中检索，则不一定。

旁白：如果没有图像归档，超声就变成了一种床旁印象，而不是一个持久的诊断记录。如果这个领域希望用超声替代常规术后胸部 X 光来评估这个终点，那么文档记录标准就非常重要。

嘉宾：另一个局限是检查时间。超声是立即完成的，而胸部 X 光可以在四小时内完成。在这段时间内，液体可能重新积聚，从而造成差异。作者承认这是务实设计的一部分。

旁白：患者选择也很重要。研究排除了包裹性或复杂性胸腔积液。这一点很关键，因为复杂胸膜腔可能正是需要更广泛影像概览，甚至需要 C T 检查的情况。

嘉宾：而且这个队列中恶性胸腔积液比例很高，这很可能导致受困肺比例较高，约为百分之五十。如果研究人群主要是漏出性积液，比如心力衰竭相关积液，那么结果可能会不同，因为在这种人群中受困肺更少见。

旁白：他们还探索了受困肺的预测因素，发现男性和恶性病因是最强预测因素，优势比分别为二点三二和二点六一。这在临床上很直观，也支持在解读引流后影像时需要重视病因。

嘉宾：那么，介入肺病医生应该如何应用这些结果？

旁白：对于大量、游离性胸腔积液，在受过训练的操作者手中，胸腔穿刺抽液后立即进行超声，似乎是评估胸膜腔排空和肺复张的可靠方式。当临床问题只是“我们是否排空了液体，肺是否复张”时，这支持减少常规胸部 X 光的使用。

嘉宾：但这并不意味着胸部 X 光完全没有作用。当患者出现症状、超声窗较差、担心肺实质异常、积液复杂或包裹、需要文档记录但超声归档不可靠，或者当地操作者经验有限时，胸部 X 光仍然可能有用。

旁白：这对流程的影响很大：减少患者转运，减少辐射，加快处置，并使操作后的决策更加即时。但实施时需要培训、标准化扫描方案、图像存储，以及可与放射科相媲美的记录质量。

嘉宾：正是如此。这项研究推动超声从单纯的操作引导工具，向术后诊断模式转变。只有当系统以类似的严谨程度对待超声时，这种转变才是合适的。

旁白：本期 InterventionalPulm.com IP Journal Review 到这里结束。E V A C U T E 支持在大量、游离性胸腔积液引流后，使用胸腔穿刺抽液后超声作为评估液体排空和肺复张的可靠工具。同时，关于气胸检出、复杂积液、肺实质发现、操作者依赖性和超声图像归档，仍然存在尚未解决的问题。感谢收听。
