旁白： 欢迎来到 Interventional Pulm 点 com 的 I P 期刊回顾。今天我们将讨论 Mahmood 及其同事在美国胸科医师学会上发表的关于中央气道阻塞管理的临床实践指南，该指南于二零二五年发表在《Chest》杂志上。 
嘉宾： 这对介入肺脏病学来说是一个重要的话题。中央气道阻塞是那种大家都认为很重要的综合征之一，但一旦你开始提出具体的比较性问题，证据基础就显得出奇地薄弱：例如硬质与软质支气管镜的对比、全身麻醉与中度镇静的对比、使用支架与不使用支架的对比、监测性支气管镜与症状驱动的随访对比，以及手术与支气管镜管理的对比。 
旁白： 完全正确。该指南将 C A O 定义为气管、主支气管、中间支气管或叶支气管至少百分之五十的阻塞。它包括恶性和非恶性病因，并且在解剖学上，该论文使用了我们熟悉的内在、外在和混合型分类框架。这种区分不仅仅是描述性的。它决定了主要策略是减瘤、扩张、支架置入、全身治疗、放疗、手术还是某种组合方案。 
嘉宾： 论文中的视觉算法在这方面非常有用。在第五页，图二区分了恶性和非恶性 C A O。对于恶性 C A O，该路径强调手术适应症、支气管内肿瘤的清创或消融、全身化学免疫疗法和放疗，以及当外部压迫或肿瘤进展阻碍持久通畅时进行支架置入。对于非恶性 C A O，算法转向相关的全身药物治疗、伴或不伴切除或消融的扩张术、针对复发的局部支气管镜治疗，以及在更下游放置支架。 
旁白： 在方法学上，这是一个由 Chest 组织的多学科专家组，使用了 P I C O 问题、系统的文献回顾、Grade 方法学和改进的德尔菲法。他们筛选了九千六百八十八篇摘要，审阅了一百五十篇全文文章，并纳入了三十一项研究。这听起来像是一项巨大的工作，但结论是整体证据的确定性非常低。 
嘉宾： 这是本指南中的核心冲突。这些建议在临床上是可识别的，并且可能与许多经验丰富的气道项目现有的想法一致，但它们几乎都是有条件的，并且基于确定性非常低的证据。所以这不是一份声明“数据明确证明了最佳方案”的文件。它更像是：“鉴于有限的比较证据以及危及生命的气道疾病的现实，这是最合理的框架”。 
旁白： 让我们来梳理一下主要建议。第一项是良好实践声明：疑似 C A O 的患者应接受针对呼吸系统的全面病史采集和体格检查、胸部 C T 成像以及适当的实验室检查，特别是当考虑到非恶性病因或术前问题时。 
嘉宾： 这看似显而易见，但实际并非总是如此。这些患者常被误诊为慢性阻塞性肺疾病急性加重、哮喘、肺炎、焦虑或潜在恶性肿瘤的进展。指南特别指出了胸部和颈部 C T 对于诊断、严重程度评估、手术规划和随访的重要性。它还强调了对硬质支气管镜检查和插管至关重要的气道评估细节：张口度、牙齿状况、马氏分级、颈部活动度和甲颏距离。 
旁白： 第二个建议可能是 I P 的核心信息：对于有症状的恶性或非恶性 C A O，专家组建议将治疗性支气管镜作为全身治疗和、或局部放疗的辅助手段。有条件推荐，证据确定性极低。 
嘉宾： “辅助”这个词很重要。在恶性 C A O 中，支气管镜检查通常能争取时间、缓解阻塞、逆转肺不张、改善功能状态，并使全身治疗或放疗得以真正进行。在非恶性 C A O 中，支气管镜检查可以与血管炎、感染、炎症性疾病或移植后气道并发症的治疗结合使用。 
旁白： 指南引用了有限的比较数据。一项前瞻性研究将三十四名接受治疗性支气管镜检查的非小细胞肺癌患者与十二名拒绝接受该检查的患者进行了比较。两组均接受了放化疗。接受支气管镜检查的平均生存期为十加减九个月，而未接受的为四加减三个月，对数秩 P 值为零点零零五。呼吸困难得到缓解，整体健康状况和身体机能改善长达六个月。 
嘉宾： 还有一项类似 Evermore 的回顾性信号：接受治疗性支气管镜加放化疗的肺癌相关 C A O 患者比仅接受放化疗的患者生存率更高，报告的风险比为二点一，百分之九十五的置信区间为一点一到四点八。但我们必须小心。这些并不是明确的因果估计。选择偏倚是不可避免的。那些存活到进行支气管镜检查、能够耐受支气管镜检查或被转诊接受支气管镜检查的患者，可能与那些没有接受检查的患者本身就不同。 
旁白： 是的。其实际意义并不是说每个恶性 C A O 患者都必须进行支气管镜检查。而是说，有症状的 C A O 应该触发对治疗性支气管镜检查的紧急评估，特别是当气道通畅程度成为根治性或姑息性肿瘤治疗的限制因素时。 
嘉宾： 接下来是第三个建议：在治疗性干预中，建议使用硬质支气管镜而不是软质支气管镜。同样，这是有条件的建议，确定性极低。 
旁白： Aquire 注册数据在这里很重要。它包括了九百四十七名接受过三百八十二次软质和七百三十三次硬质治疗性支气管镜检查的患者。技术成功率（定义为将气道管腔重新开放至正常直径的百分之五十以上）非常相似：软质支气管镜为百分之九十二点七，而硬质支气管镜为百分之九十三点五，P 等于零点六二。 
嘉宾： 因此，这项建议并不是由技术成功率上的巨大数字优势驱动的。它是由操作逻辑和专家共识驱动的。硬质支气管镜提供通气、气道控制、填塞能力、大口径吸引、穿透肿瘤的能力，以及用于放置硅酮支架的平台。在近端、危急、出血、混合型阻塞的气道中，这些功能至关重要。 
旁白： 站在反方立场的疑问是这项建议是否可能被过度泛化了。对于远端脑叶阻塞、非危重病变、特定的支气管内疾病或具有特定软镜专长的中心，软质治疗性支气管镜检查可能是合理的。但对于高风险的近端 C A O，指南明确倾向于具备硬镜能力。 
嘉宾： 这对医疗系统有着深远的影响。如果一家医院正在管理恶性气道阻塞，但缺乏硬质支气管镜、麻醉科的配合、支架库存以及熟悉气道救援的人员，该指南隐含地支持建立转诊途径，而不是在边缘条件下临时进行最终的气道治疗。 
旁白： 第四个建议涉及镇静：建议在治疗性支气管镜检查中使用全身麻醉或深度镇静，而不是中度镇静。Aquire 数据再次显示在技术成功率上没有差异，但与中度镇静相比，全身麻醉或深度镇静与更少的并发症相关，多变量比值比为零点四二，百分之九十五置信区间为零点二一到零点八三，P 等于零点零一三。 
嘉宾： 并且使用肌松药也与更少的并发症相关：百分之三对比百分之六点七，P 等于零点零零六。这非常具有相关性，因为在保留自主呼吸和实现手术控制之间一直存在理念上的冲突。在经验丰富的医生手中，配合正确的团队，控制通气和肌肉松弛可以减少咳嗽、移动、低氧血症发作和手术混乱。 
旁白： 但这也是个体解剖学和生理学重要的地方。一名患有几乎完全的远端气管阻塞、严重的动态塌陷或双侧主支气管受累的患者，与一名患有短段良性狭窄且病情稳定的患者是不同的。指南适当地强调了与麻醉科进行多学科规划的重要性。 
嘉宾： 第五项建议令人耳目一新，不那么教条：在全身麻醉下进行硬质治疗性支气管镜检查时，可以使用喷射通气或控制性或自主辅助通气。在 Aquire 研究中，七百一十四名患者使用了控制性或自主辅助容量循环通气，二百三十名患者使用了喷射通气。技术成功率分别为百分之九十二点九和百分之九十六点一，在呼吸困难、生活质量、并发症或与并发症相关的死亡率方面没有显著差异。 
旁白： 所以这不是一个“必须使用喷射通气”的指南。它更多的是关于将通气策略与病变解剖、设备、麻醉学专长和救援计划相匹配。他们还提到了针对严重气管或双侧主气管阻塞的 E C M O 技术，但也适当地指出，其理想的患者选择和并发症情况目前尚不完全明了。 
嘉宾： 第六个建议：对于伴有支气管内疾病的症状性 C A O，专家组建议进行肿瘤或组织切除和、或消融，以实现气道通畅。这很直观，但指南坦诚地表示，目前还没有发现比较性的恶性肿瘤切除研究。其支持证据来自非恶性疾病中质量较低的比较数据以及恶性梗阻中的非比较性病例系列。 
旁白： 该指南列出了常见的治疗方式：活检钳清创、硬质镜取芯、微型清创术、冷冻清创术、激光、电灼和氩气等离子凝固术。它还提出了一个安全要点，即当使用基于热能的治疗时，吸入氧浓度（F I O 2）应降至零点四或更低，并且应尽量减少易燃设备周围的着火风险。 
嘉宾： 这一点虽然基本但没有商量的余地。气道着火虽然罕见，但后果是灾难性的，并且它是可以预防的，因此应该被纳入每一个涉及热疗的手术暂停检查清单中。 
旁白： 第七项建议侧重于非恶性狭窄：建议单独进行气道扩张或与其他方式结合使用。有趣的数据来自于特发性声门下狭窄。在一项包含八百一十名患者的前瞻性多中心研究中，扩张术三年的复发率为百分之二十八，而内镜二氧化碳激光切除加辅助药物治疗的复发率为百分之十二点四。在五年时，扩张术的复发率为百分之五十，而内镜切除药物治疗方法的复发率为百分之三十。 
嘉宾： 这就让将扩张术作为“一线”治疗的观点变得复杂了。它可能是一线治疗，因为它容易操作、可重复且通常有效，但复发很常见。真正的问题在于分型：简单的网状狭窄还是复杂的软骨损伤，特发性声门下狭窄还是插管后狭窄，炎症性疾病还是移植吻合口狭窄。单一的建议无法完全涵盖这种异质性。 
旁白： 第八项建议是支架置入：对于有症状的恶性或非恶性 C A O，如果其他治疗性支气管镜和全身治疗失败，并且在潜在疾病允许的情况下，建议放置支架。 
嘉宾： 我喜欢这种措辞，因为它抵制了在每个看起来可怕的气道中放置支架的诱惑。支架作用强大，但它们并非没有副作用。黏液栓塞、肉芽组织增生、移位、断裂和感染都不是理论上的并发症。指南基本上是说：当无法通过其他方式维持气道通畅时使用支架，特别是在存在外部压迫或肿瘤进展时；但如果仅靠清创就能提供持久的气道，则应避免使用支架。 
旁白： Spock 试验值得关注。七十八名由非小细胞肺癌引起的恶性支气管内 C A O 患者在肿瘤清创后被随机分配接受硅酮支架或不使用支架。在无复发生存期或总生存期方面没有差异，但放置支架可以产生更持久的呼吸困难改善，并减少了重复进行治疗性支气管镜检查的需求。在对一线化疗无效或仅接受放疗或姑息治疗的患者亚组中，这一信号最强，局部复发的风险比为零点二一，百分之九十五置信区间为零点零六至零点七四。 
嘉宾： 在 Aquire 研究中，在进行的成千上百一十五次治疗性支气管镜检查中，放置了四百零六个支架。支架置入与技术成功相关，比值比为十一点九，但与呼吸困难的改善、生活质量或并发症没有关联。这提醒了我们：技术上成功的气道并不总是以患者为中心的成功。 
旁白： 对于良性疾病，该指南保持谨慎态度，特别是因为美国食品药品监督管理局（F D A）针对良性气管疾病使用金属支架发出了警告。新一代全覆膜金属支架可能更安全，但证据仍然有限。在良性疾病中，放置支架通常应该感觉像是一种尝试、一种桥接或在反复失败后的退路，而不是随意的首选操作。 
嘉宾： 第九个建议是故意留有余地的：放置支架后，建议进行常规的监测性支气管镜检查或症状驱动的支气管镜检查。证据基本上是一项回顾性研究。在该研究中，三个月内的常规监测在三十九名患者中的十六名中发现了与支架相关的并发症，但无论如何他们大多数都有症状。在症状驱动组中，在三十一名有症状的患者中发现了二十六例并发症。 
旁白： 因此，该指南并没有强制要求常规进行监测性支气管镜检查。它建议在适当时进行临床随访、使用高渗盐水雾化等气道清除策略，以及 C T 评估。实际的选择取决于支架类型、适应症、患者的可靠性、分泌物负担、既往的黏液栓塞情况、肿瘤学发展轨迹以及进行紧急支气管镜检查的便利性。 
嘉宾： 第十个建议涉及局部支气管镜治疗（光动力疗法 P D T、近距离放射治疗、冷冻疗法、病灶内化疗、类固醇、丝裂霉素 C），并指出使用或不使用这些疗法都是合理的。这听起来可能不像是一个具体的建议，但它反映了现有的证据。数据过于异质且存在偏倚，无法得出强有力的指示。 
旁白： 在恶性疾病中，一项回顾性比较发现，P D T 治疗至需要再次干预的平均时间为一百四十七天，而非 P D T 消融加放化疗的平均时间为九十八天，但 P 等于零点二零。在良性气管狭窄中，一项小型回顾性研究报告了四个月的成功率：扩张术为百分之十五，类固醇注射为百分之十八点二，丝裂霉素 C 应用为百分之七十五。这很有趣，但并非决定性的。 
嘉宾： 最后是手术。对于非恶性 C A O，专家组建议进行开放式手术切除或治疗性支气管镜检查。对于患有支气管内肿瘤的恶性 C A O，可以使用手术切除或治疗性支气管镜检查来初步缓解阻塞，但有一个重要的注意事项，即手术在局限性疾病和类癌型肿瘤中的作用最为明确。 
旁白： 特发性声门下狭窄的数据再次具有指导意义。在三年时，复发率分别为：扩张术百分之二十八，内镜激光切除加辅助药物治疗百分之十二点四，手术切除百分之一点二。在五年时，复发率分别为百分之五十、百分之三十和百分之五。但是与其他疗法相比，手术带来的声音结果更差。 
嘉宾： 这是一个完美的例子，说明了为什么以患者为中心的结果至关重要。“最好的气道”并不自动等于最好的结果，如果声音、吞咽功能受损，围手术期风险过高，或患者无法接受这些影响的话。对于复杂的复发性狭窄，手术可能是最持久的选择。对于简单的狭窄、高风险的手术候选人或优先考虑保留声音的患者，支气管镜管理可能是完全合适的。 
旁白： 那么，这份指南为介入肺脏病学（I P）领域的受众增加了什么？ 
嘉宾： 它确立了一种务实的气道处理理念：仔细评估，做好影像学检查，尽早让合适的团队介入，将治疗性支气管镜检查作为一种辅助手段而不是孤立的事件，在进行高风险的治疗工作时倾向于使用硬质支气管镜和更深的麻醉，将支架保留给无法通过其他方式维持气道通畅的情况，并在特定的良性狭窄和局限性恶性疾病中保留手术的讨论。 
旁白： 仍然不确定的几乎是所有的比较性问题。哪种消融方式最好？ 谁在清创后真正需要支架？ 最佳的监测策略是什么？ 哪种良性狭窄表型应该尽早进行手术？ 针对哪种解剖结构，哪种通气策略最安全？ 除了管腔直径，我们如何衡量成功？ 
嘉宾： 这可能是最重要的批评点。该领域需要前瞻性的、以患者为中心的、针对特定表型的研究。将技术成功定义为使气道恢复到正常直径的百分之五十以上是有用的，但患者关心的是呼吸困难、声音、分泌物负担、住院天数、接受癌症治疗的能力、避免气管切开、持久性以及生活质量。 
旁白： 总结一下：这份《Chest》指南并不是一份具有高确定性证据的蓝图。它是一个基于有限数据、为高风险临床综合征建立的以共识为导向的框架。对于介入肺科医生来说，它支持了许多气道项目已经相信的观点：中央气道阻塞应经过深思熟虑地处理，具备多模式能力、麻醉科的配合、多学科协调，并且在放置支架和其他耐用植入物时要非常谨慎。 
嘉宾： 也许最诚实的信息是，中央气道阻塞并不是一种单一的疾病。恶性外源性压迫、脆弱的支气管内肿瘤、插管后气管狭窄、特发性声门下狭窄、移植吻合口狭窄和气管支气管软化症都属于 C A O 的范畴，但它们不应被视为可以互换治疗的疾病。 
旁白： 这是个很好的收尾。这里是 Interventional Pulm 点 com 的 I P 期刊回顾。今天我们回顾了 Mahmood 及其同事在《Chest》杂志上发表的关于中央气道阻塞管理的指南：对于介入肺脏病学中技术要求最高的领域之一，这是一个在临床上实用且适度谨慎的框架。
