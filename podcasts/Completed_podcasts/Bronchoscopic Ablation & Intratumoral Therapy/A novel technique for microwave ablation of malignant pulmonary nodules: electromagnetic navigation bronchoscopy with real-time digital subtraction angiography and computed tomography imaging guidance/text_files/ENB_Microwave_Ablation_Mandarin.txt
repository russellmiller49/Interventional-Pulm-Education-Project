InterventionalPulm.com IP Journal Review：E N B、D S A 和 C B C T 引导的恶性肺结节支气管镜微波消融

预计时长：九分钟

文章类型：原创研究；单中心技术可行性研究和技术论文

旁白：欢迎收听 Interventional Pulm 点 com I P Journal Review。今天我们讨论 Xu 等人在二零二五年发表于 European Journal of Cardio-Thoracic Surgery 的研究。这篇文章关注电磁导航支气管镜，联合实时数字减影血管造影和锥形束 C T，引导恶性肺结节的微波消融。

嘉宾：这是一篇非常偏技术和流程的文章。它的重点不是证明长期肿瘤学疗效，而是提出一个很实际的问题：在常规 E N B 和 C B C T 工作流程上，加入实时二维 D S A，能不能让支气管镜消融更加精准？

旁白：对。这里的临床问题很熟悉。E N B 可以把我们带到外周靶病灶附近，但当治疗终点是消融区完整覆盖，而不只是取得组织时，“附近”并不一定够。活检工具有时可以容忍一点定位误差。但消融天线不太能容忍，尤其是小的、深部的、磨玻璃或者部分实性结节。

嘉宾：没错。文章把这个限制讲得很清楚。E N B 会受到配准误差、呼吸运动、肺不张，以及支气管镜本身造成的靶点位移影响。C B C T 有帮助，因为它可以提供三维确认。但 C B C T 不是连续实时引导。如果每一次调整都需要再做一次旋转扫描，手术时间和辐射暴露就可能明显增加。

旁白：所以作者提出了一个融合工作流程。术前 C T 被导入 SuperDimension 导航平台。患者接受全身麻醉，并置入喉罩。然后进行术中 C T 扫描，分割肺结节，做三维重建，再把这个重建出来的靶点信息导入实时 D S A 系统。

嘉宾：接下来，可定位导丝通过支气管镜工作通道，在 E N B 引导下推进到靶点附近。当导丝接近结节时，使用实时 D S A 来确认它是否真的到达了理想位置。如果位置不满意，可以在 E N B 和 D S A 融合反馈下动态调整导丝，包括利用 D S A 的三百六十度视角。之后撤出可定位导丝，换入消融探针，再次确认探针位置，然后进行微波消融。

旁白：文章中的流程图很有用，因为它显示了这个技术的基本节奏：E N B 把操作者带到目标区域，D S A 提供实时精细调整，C B C T 在消融前确认位置，然后进行消融，消融后再用 C B C T 评估消融区和并发症。最有意思的图像是 D S A 调整示意图。在图中，E N B 显示的目标位置和实际目标位置有偏差，而 D S A 让导丝可以向前方和下方重新调整。

嘉宾：这就是这篇文章的技术核心。它不只是“E N B 加 C B C T”。作者真正想测试的附加价值，是实时 D S A 能否弥合导航和确认成像之间的差距。

旁白：看一下研究队列。这是一项单中心研究，纳入二零二四年一月至十一月治疗的三十九名患者，共治疗五十一个恶性肺结节。入选标准包括结节直径小于或等于三厘米，影像学特征提示恶性，以及患者不适合手术、拒绝手术，或者适合混合策略，也就是切除一部分结节，同时消融另一部分结节。

嘉宾：患者中位年龄为六十一岁，女性占多数，三十二名女性，七名男性。结节中位直径为十二毫米。这个大小很重要。这些病灶都比较小，而且多数不是实性结节。三十个是纯磨玻璃结节，十六个是部分实性结节，只有五个是实性结节。

旁白：这也是泛化性方面的一个重点。一个以十二毫米、以亚实性结节为主的队列，和较大实性转移灶或者中央型复发肿瘤的队列非常不同。技术挑战是真实存在的，但肿瘤生物学和随访预期也不一样。

嘉宾：肺功能情况也值得注意。第一秒用力呼气量的中位数是二点一四升，第一秒用力呼气量占预计值百分比的中位数是九十六点七。所以，虽然研究包括不适合手术或拒绝手术的患者，但这并不是一个单纯由肺储备严重受限患者组成的队列。

旁白：从操作结果看，E N B 和 C B C T 融合引导步骤在所有病例中都成功完成。从可定位导丝开始到达结节最近位置的中位导航时间是十二分钟，范围为六到三十二分钟。每次操作中 C B C T 扫描次数的中位数是三次，范围为二到七次。

嘉宾：一个临床上非常有意思的数据是初始靶向误差。初始导航后，可定位导丝尖端到结节边缘的中位距离是十毫米，最大达到二十五毫米。考虑到结节中位直径本身只有十二毫米，这个误差并不小。

旁白：对。这个数字几乎就是这篇文章的核心论点。如果单纯 E N B 让你距离结节边缘还有十毫米，那么实时校正就不是锦上添花。它可能决定你是在治疗病灶，还是在治疗病灶旁边的肺组织。

嘉宾：在 D S A 和 C B C T 融合引导帮助下，作者报告所有病例中消融天线都成功放置在结节边缘，中位误差为一毫米，范围为零到五毫米。这是一个很突出的技术结果。不过仍然需要谨慎解读，因为研究没有对照组。

旁白：微波消融的能量设置为四十到六十五瓦，持续五到十分钟，根据结节大小和探针位置进行调整。必要时使用多次重叠消融。消融时间中位数为十二分钟。每个结节的消融次数为一到四次，中位数为两次。

嘉宾：从开始导航到最终 C B C T 确认，整个操作的中位时间是八十五分钟。范围很宽，从三十六到一百四十六分钟。C B C T 扫描产生的辐射剂量，以参考点空气比释动能，也就是 R P A K 报告，中位数为二百七十六毫戈瑞，范围为一百零七到九百一十三毫戈瑞。

旁白：这个辐射指标需要谨慎表述。作者明确指出，R P A K 不等同于患者实际吸收剂量。它是 C B C T 系统提供的参考测量值，并没有纳入人体内的衰减和散射。因此，它适合用于比较不同成像方案，但不应该被直接解释为患者实际吸收剂量。

嘉宾：关于结局，最主要的结果是技术成功率。五十一个结节中有四十七个达到技术成功，也就是百分之九十二点二。技术成功定义为即刻消融后 C B C T 和术后第一天胸部 C T 上，消融区覆盖结节。四个结节为部分覆盖，作者提到在后续随访中可能出现完全覆盖。

旁白：安全性在这个初始系列中看起来不错。没有重大并发症。轻微并发症包括两名患者咯血，三名患者术后发热，均出现在术后第一天，并且都自行缓解，没有进一步干预。

嘉宾：这当然令人安心，特别是因为气胸是支气管镜消融和经皮消融策略之间的一个重要差异点。但这里要加入一点反方观点。三十九名患者没有观察到重大并发症，并不意味着重大并发症发生率是零。它只说明在这个早期、经过选择的队列中，没有观察到重大并发症。

旁白：同意。而且这项研究是描述性的。作者没有进行推断性统计分析，也没有对照组。所以我们不能说这种技术优于经皮 C T 引导微波消融，也不能说它优于单纯 E N B 加 C B C T、机器人支气管镜加 C B C T，或者 S B R T。我们可以说，这项技术在这个中心是可行的，并且产生了较高的即刻技术成功率。

嘉宾：另一个关键限制是随访。作者没有评估长期结局，比如局部肿瘤进展或生存，因为早期肺癌相对惰性，而且随访时间有限。对于消融来说，即刻覆盖是必要条件，但不是充分条件。真正的肿瘤学终点是持久的局部控制。

旁白：这对磨玻璃和部分实性病灶尤其重要。如果很多病灶属于惰性的腺癌谱系结节，短期影像学成功可能看起来非常好。真正的问题是六个月、十二个月、二十四个月以及更长时间后会怎样，而且需要使用标准化的局部进展和治疗失败定义。

嘉宾：还有一个病理学问题。入选标准包括影像学特征提示恶性的结节。在真实的多学科决策中，这有时是合理的，特别是多个原发性肺癌模式。但如果要评估疗效，组织学确认和单个病灶层面的诊断就很重要。

旁白：另一个实施问题是基础设施。这不是一个低资源流程。它需要 E N B，术中 C T 或 C B C T 能力，实时 D S A 集成，图像重建，麻醉支持，以及一个能够熟练在支气管镜、高级成像和消融之间切换的团队。这和普通内镜室里的标准支气管镜完全不同。

嘉宾：这就提出了推广问题。它能否被广泛采用，还是应该被看作专家中心的创新？文章倾向于强调未来潜力，但现实障碍很明显，包括大型设备投入，辐射流程，房间可用性，培训，与放射科或复合手术室团队的协调，以及支气管镜消融的资质认证。

旁白：另一方面，患者选择的临床场景确实存在。文章中的代表性病例让这个理由变得具体：多原发肺癌，既往肺叶切除，肺储备有限，深部病灶，或者混合策略，也就是一个病灶切除，另一个更深的病灶消融。这些正是需要保存肺实质和精准靶向的情况。

嘉宾：这可能是这项技术最有吸引力的地方。它不是作为手术或 S B R T 的全面替代，而是作为精心选择患者的一种工具：多发结节，深部外周靶点，既往切除史，储备有限，或者患者在多学科咨询后拒绝手术。

旁白：文章也把消融放在 S B R T 的背景下讨论。作者指出，S B R T 是医学上不能手术或拒绝手术的早期非小细胞肺癌患者的既定选择。他们也把消融作为部分患者的替代方案来讨论，尤其是在患者个体特征、患者偏好和机构经验支持消融时。

嘉宾：这个框架是合理的。临床问题不是“这会不会取代 S B R T”。问题是“对哪些患者来说，支气管镜热消融在局部治疗、组织保存、可重复性、操作风险和随访清晰度之间，能够提供更好的平衡”。

旁白：对介入肺病学听众来说，这篇文章带来几个重要观点。第一，它量化了 E N B 接近靶点和真正到达靶点边缘之间的差距。第二，它提出实时 D S A 可以在不反复进行 C B C T 旋转扫描的情况下纠正这个差距。第三，它显示，在一个经过选择的单中心队列中，使用这种融合方法的支气管镜微波消融，可以实现较高的即刻覆盖率，并且观察到的急性并发症较低。

嘉宾：但它还没有回答更大的问题。我们仍然需要多中心可重复性，学习曲线数据，标准化辐射评估，与其他引导策略的比较，成本和流程分析，最重要的是持久的局部控制。

旁白：所以最终结论要保持平衡。这是一项优雅的技术可行性研究，提出了一个对介入肺病学非常相关的操作理念。对于已经开展高级影像引导支气管镜和支气管镜治疗的中心，它应该会引起兴趣。但不应该把它解读为已经证明这个流程能改善长期肿瘤学结局，也不应该认为它明天就应该被广泛采用。

嘉宾：说得好。现阶段，这篇文章更适合带到肿瘤委员会讨论、操作创新会议和消融项目规划中。它让我们更清楚地思考支气管镜治疗到底需要多高的精准度，以及需要哪些成像工具来让这种精准度真正可信。

旁白：以上就是本期 Interventional Pulm 点 com I P Journal Review。今天我们讨论了 Xu 等人关于 E N B 联合实时 D S A 和 C B C T，引导恶性肺结节支气管镜微波消融的研究。实际信息是：可以保持谨慎的热情。这个流程很有前景，即刻技术表现令人印象深刻，但证据仍然处于早期阶段，需要更长随访和更广泛验证。

嘉宾：而且在操作肿瘤学中，病例结束时的影像，并不等同于肿瘤学结局。它只是证明结局的起点。

旁白：感谢收听 Interventional Pulm 点 com I P Journal Review。
