Interventional Pulm 点 com IP Journal Review：支气管镜检查期间，高流量鼻导管氧疗与常规氧疗的比较

预计时长：约9分钟

文章类型：随机对照试验的系统综述和荟萃分析

旁白：欢迎收听 Interventional Pulm 点 com IP Journal Review。在这个节目里，我们聚焦一篇文章，讨论它对介入肺脏病学实践到底意味着什么。今天讨论的是 Fliess de Castro 及同事发表在二零二六年 Journal of Bronchology and Interventional Pulmonology 上的文章，题目是“支气管镜检查期间，高流量鼻导管氧疗与常规氧疗的比较”。这是一项随机对照试验的荟萃分析。

嘉宾：这是一个非常实用的话题。支气管镜检查期间的低氧血症，并不是少见的小麻烦。它会影响操作能否连续完成，影响镇静策略，影响是否需要和麻醉团队进一步协调，有时甚至会决定一个诊断性或治疗性操作能否安全完成。所以，虽然高流量鼻导管，也就是 H F N C，是大家已经熟悉的技术，但真正的问题是：证据是否支持我们在支气管镜检查中更主动地使用它，而不是只在患者看起来风险很高时才临时拿出来。

旁白：对。它的生理学基础其实很清楚。常规氧疗，也就是 C O T，可以通过鼻导管、普通面罩、文丘里面罩或者储氧面罩来给氧。但这些方式有局限：吸入氧浓度，也就是 F I O 二，可能不稳定；没有明显的 P E E P 效应；对解剖死腔的清除也不可靠。相反，高流量鼻导管可以提供加温加湿的气体，流量可以超过患者的吸气需求，能够提供更稳定的 F I O 二，产生一定的低水平正压，并冲洗鼻咽部死腔。

嘉宾：这很重要，因为支气管镜检查本身就是一个对呼吸生理很不友好的环境。镜体会缩小气道腔。镇静会降低通气驱动。通气血流匹配可能变差，气道阻力可能增加，还可能出现间歇性气道阻塞。如果患者同时有肥胖、阻塞性睡眠呼吸暂停、慢性阻塞性肺疾病、间质性肺病、肺动脉高压或者心力衰竭，那么安全余量会很快变小。

旁白：作者采用的是系统综述和荟萃分析的方法。他们在二零二五年六月检索了 PubMed、Embase 和 Cochrane，遵循 PRISMA 方法，并在 PROSPERO 注册了方案。纳入的是成年人柔性支气管镜检查中，比较 H F N C 与常规氧疗策略的随机试验。主要结局是去饱和事件。次要结局包括最低 S P O 二、操作时间、患者舒适度和镇静剂量。

嘉宾：这里的 PRISMA 流程图值得一提，因为它显示了证据基础仍然比较有限。作者最初找到五百三十五条记录，删除一百五十条重复记录，筛查三百八十五条，评估二十三篇全文，最终纳入十四项随机试验。所以，这个分析的优势是只纳入随机证据，但整个研究池仍然不算大。

旁白：总体来看，这项荟萃分析包括二千四百八十名患者。其中，一千二百六十三名患者接受 H F N C。纳入的操作包括鼻纤维镜检查、线性和径向支气管内超声，也就是 E B U S、柔性支气管镜、经支气管针吸活检、标准支气管镜和经鼻支气管镜。因此，这篇文章和介入肺脏病学的日常流程很相关，尤其是 E B U S 和诊断性柔性支气管镜。

嘉宾：主要结果很有力。与常规氧疗相比，H F N C 减少了去饱和事件。合并风险比为零点四一，百分之九十五置信区间为零点二九到零点五九，p 值小于零点零零零一。用简单的操作语言来说，使用 H F N C 后，去饱和风险不到原来的一半。

旁白：但是，异质性很高。对于去饱和事件，I 平方为百分之八十一点五。因此，效应方向很有说服力，但确切效应大小不是一个可以直接套用于所有支气管镜室的干净数字。

嘉宾：正是这样。这里就变得复杂了。文章第四页的森林图在视觉上明显支持 H F N C 减少去饱和，但各研究之间存在差异：患者基础风险不同，操作类型不同，镇静深度不同，给氧设置不同，低氧血症定义也不同。S P O 二低于百分之九十的一次去饱和，不等于持续性低氧，也不等于低于阈值的累积时间，更不等于一次具有临床意义的操作中断。

旁白：氧合结果也支持 H F N C。H F N C 将最低 S P O 二提高了平均五点一零个百分点，百分之九十五置信区间为三点三零到六点九一。p 值同样小于零点零零零一。不过，异质性仍然很高，I 平方为百分之八十七点四。

嘉宾：在合适的患者身上，最低血氧饱和度提高五个百分点是有临床意义的。在中度或深度镇静下做 E B U S 时，从百分之八十六到百分之九十一，不是一个装饰性变化。它可能决定是继续操作，还是暂停操作、抬下颌、升级给氧，或者紧急呼叫麻醉支持。

旁白：另一方面，以患者体验和流程为中心的结局更中性。操作时间没有显著差异：平均差为负零点七三分钟，置信区间从负一点七三到正零点二七。患者舒适度也没有显著差异，主要结果中的标准化平均差约为负零点零九。

嘉宾：这一点很重要，因为任何给氧设备都可能带来一个实际问题：它会不会碍事。H F N C 通常可以保留经口操作通道，并且比无创通气侵入感更低。但在这个合并分析中，它并没有明显提高患者舒适度，也没有明显缩短操作时间。它最主要的作用，还是改善氧合。

旁白：镇静剂量是一个有意思的细节。合并分析发现，H F N C 组的镇静需求略高，标准化平均差为零点一八，置信区间为零点零五到零点三一，p 值为零点零零五九。

嘉宾：这个结果不应该被过度解读为 H F N C 让患者需要更多镇静。更合理的解释可能是临床行为的变化。如果操作者感到患者氧储备更大，可能更愿意接受或给予更深的镇静。作者的敏感性分析也提示要谨慎：当排除 Darie 及同事的研究后，镇静剂量的差异就不再具有统计学意义。

旁白：操作时间的结果也比较敏感。排除 Zhang 及同事的研究后，操作时间转向统计学上显著缩短，结果支持 H F N C。因此，最稳健的结局是去饱和事件和最低血氧饱和度。次要结局有参考价值，但稳定性较差。

嘉宾：偏倚风险评估总体上令人放心。多数试验被认为是低偏倚风险，主要担忧来自无法盲法。这并不奇怪。在支气管镜室里，很难把 H F N C 与面罩或低流量鼻导管真正做成盲法。GRADE 评估显示，去饱和事件、最低 S P O 二和镇静剂量的证据确定性为中等；操作时长为高确定性；患者舒适度为低确定性。

旁白：我们再谈谈对照组。一个问题是，“常规氧疗”并不是一种统一的东西。每分钟几升的鼻导管、文丘里面罩、储氧面罩和无创通气，在生理学上是不同的对照。把它们合并分析很实用，但也会模糊床旁真正的问题。

嘉宾：没错。真实操作中的问题常常不是“H F N C 对比其他任何方式”。真正的问题是：对于这个患者、这个镇静计划、这个预计支气管镜时长，以及这个气道通路需求，H F N C 是否优于当前可用的替代方案？对于一个低风险患者的短时间、无镇静观察，增量价值可能很小。但对于一个有慢性阻塞性肺疾病或阻塞性睡眠呼吸暂停风险的患者，在较长时间 E B U S 中，它的价值就完全不同。

旁白：作者也强调了几个试验层面的信号。Wang 及同事提供了一个较大的普通人群队列，并显示去饱和事件减少。Darie 及同事研究了慢性阻塞性肺疾病患者，并报告累积低氧时间减少。Zhang 及同事聚焦于阻塞性睡眠呼吸暂停风险患者，发现低氧血症明显减少。Ben-Menachem 及同事则在肺移植受者中显示了获益。

嘉宾：同时，Burton 及同事没有发现氧合优势，这同样有启发性。作者提出的可能解释包括：更严格地匹配 F I O 二、更轻的镇静，以及风险较低的患者。这很重要，因为当对照组已经优化，而且患者群体不那么脆弱时，H F N C 的效果可能看起来没那么惊人。

旁白：还有一个措辞问题值得指出。方法部分描述的是成年人柔性支气管镜研究，并排除了硬质支气管镜。可是讨论部分后面使用了更宽泛的操作覆盖语言。对于介入肺脏病学听众来说，这个区别很重要。全身麻醉下的硬质支气管镜，是一个完全不同的气道和通气问题，不同于中度镇静下的柔性支气管镜或 E B U S。

嘉宾：同意。这篇文章支持在支气管镜检查中使用 H F N C，但听众要小心，不要自动外推到硬质支气管镜、喷射通气、治疗性气道去阻塞，或者那些由麻醉团队通过不同气道设置控制通气策略的病例。

旁白：那么，介入肺脏病医师应该如何把这个结果落实到实践中？一个合理的理解是：当预防去饱和是重要目标时，应该强烈考虑 H F N C。比如高风险 E B U S、长时间取样、肥胖患者、有阻塞性睡眠呼吸暂停风险的患者、慢性阻塞性肺疾病、基础氧合边缘、肺移植受者，或者一旦中断操作就会带来较高临床代价的患者。

嘉宾：它也有流程层面的影响。H F N C 需要设备可用，团队熟悉，操作前有设置时间，并且要有升级方案。鼻导管应该在镇静开始前放好。流量和 F I O 二需要有意选择，而不能把它当成一根装饰性的管子，接在一个特别热情的流量表上。

旁白：还有和麻醉团队之间的接口。H F N C 可能让中度或深度镇静时氧储备更好，但它不应该变成忽视通气的许可证。氧合不等于通气。在慢性阻塞性肺疾病、肥胖低通气，或者长时间深镇静的患者中，二氧化碳监测和气道处理仍然重要。

嘉宾：作者指出，在各项试验中，H F N C 很少加重二氧化碳潴留，这一点令人放心。但在合并的支气管镜试验中没有明显高碳酸血症信号，并不意味着不需要根据患者情况进行监测。尤其当镇静变深时，脉搏血氧仪可能看起来非常漂亮，而通气却在安静地恶化。脉搏血氧仪有时候是一个很有魅力的骗子。

旁白：那患者舒适度呢？合并结果没有显示显著差异。临床上，有些患者喜欢 H F N C，因为它是经鼻的，而且加温加湿。另一些患者不喜欢鼻腔内的高流量气体。无创通气可能氧合效果很好，但可能影响支气管镜通路和患者耐受。因此，舒适度很可能取决于具体情境，而低确定性的证据评级也反映了这一点。

嘉宾：最大的限制仍然是异质性。低氧血症定义不同，支气管镜操作不同，镇静方案不同，给氧设置不同，患者风险也不同。合并估计很有帮助，但不能替代科室层面的流程设计。

旁白：另一个限制是，研究结局主要是操作性和生理性的。去饱和确实重要，但这篇文章没有证明它会影响重大不良事件、住院、插管、诊断率或成本效益。这些结局更难研究，但恰恰是行政管理者、麻醉团队和操作室负责人最终会问的问题。

嘉宾：未来研究大概应该在选定的高风险人群中，直接比较 H F N C 与无创通气，标准化低氧血症定义，并纳入流程指标：设置时间、操作中断、升级事件、人员负担和成本。一个设备可以在生理学上非常优雅，但仍然可能很难一致地融入实际流程。

旁白：所以，底线是：这项荟萃分析加强了一个观点，也就是 H F N C 能改善支气管镜检查期间的氧合。减少去饱和事件和提高最低 S P O 二，是最关键的发现。操作时间和患者舒适度看起来相近。镇静剂量可能略高，但这个结果不够稳定，也很可能受到临床行为的混杂影响。

嘉宾：在实践中，这支持把 H F N C 作为有意义低氧风险支气管镜检查的一线选项，尤其是在高风险柔性支气管镜和 E B U S 流程中。但这并不意味着每一个低风险支气管镜都需要 H F N C，也不能替代审慎的镇静、气道评估和升级计划。

旁白：说得很好。这篇文章为介入肺脏病医师提供了更强的证据基础，支持很多团队可能已经怀疑的事情：支气管镜检查期间，更好的氧气输送可以减少去饱和，但患者选择、镇静策略、对照方式和流程细节，决定了这种获益到底有多重要。

嘉宾：正是如此。合并分析的菱形支持 H F N C，但支气管镜室仍然需要继续思考。
