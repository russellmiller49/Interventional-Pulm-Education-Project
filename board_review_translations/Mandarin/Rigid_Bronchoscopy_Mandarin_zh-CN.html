硬质支气管镜术：适应证、技术与故障处理

考试内容对应与范围

领域：硬质支气管镜术／异物取出

本章与美国支气管镜与介入肺脏病学协会（AABIP）介入肺脏病学专科考试的操作知识标准相对应，系统整合当前适应证与禁忌证、麻醉与通气策略、逐步操作技术（包括肿瘤减瘤与异物取出）、故障处理、并发症、结局，以及有助于考试和临床实践的高频要点。

学习目标

  • 区分硬质支气管镜术（RB）的适应证与禁忌证，并判断何时应优先选择硬镜而非软质支气管镜。
  • 选择可针对计划干预优化安全性的麻醉与通气策略，包括全静脉麻醉（TIVA）、自主－辅助通气和喷射通气。
  • 完成硬镜插管的核心步骤和支气管腔内减瘤顺序（去血管化 → 机械削切 → 凝固基底），并采用胜任力核查表进行评估。
  • 处理大咯血、取出异物（包括整块取出），并应用硬镜治疗良性狭窄（单纯型与复杂型）。
  • 预判、预防并处理围操作期并发症，理解登记研究中技术成功和死亡风险的预测因素。

高频考点一页通

核心概念：对于急性中央气道梗阻（恶性或良性）、大咯血和复杂异物取出，硬镜是首选器械，因为其可提供更佳的通气控制、吸引能力、出血压迫止血以及大型器械通道。

禁忌证：
绝对禁忌证：颈椎不稳定。
相对禁忌证：既往颈椎融合、血流动力学不稳定、严重低氧血症、凝血功能障碍／血小板减少，以及术者经验不足。

麻醉：硬镜在全身麻醉下完成。由于硬镜属于开放式系统，全静脉麻醉（TIVA）通常优于吸入麻醉。

通气：
自主－辅助通气：可提供呼气末正压（PEEP）并进行闭合系统监测。
喷射通气：在热消融前可迅速降低吸入氧浓度（FiO₂），但无法监测气道压力，并存在气压伤风险。

成功率：恶性中央气道梗阻（CAO）的治疗性支气管镜技术成功率很高（约93%）。基线症状负担越重，呼吸困难改善通常越明显；仅累及肺叶支气管者获益较少。

成功预测因素：支气管腔内病变和置入支架可提高成功率；ASA分级＞3、肾衰竭、左主支气管病变和气管食管瘘（TEF）可降低成功率。

并发症：总体发生率约3.9%，操作相关死亡率约0.5%。急诊／紧急病例、ASA分级＞3、再次操作以及采用中度镇静时，风险更高。

死亡率：30天死亡率主要反映疾病负荷；与ASA分级＞3、ECOG体能状态＞1、腔内型或混合型梗阻及支架置入相关，尤其是Y形支架。

减瘤顺序：凝固／去血管化 → 用硬镜斜口进行机械削切 → 凝固肿瘤基底。（存在外压型或混合型梗阻或气道不稳定时置入支架。）

良性狭窄：
单纯型（黏膜性）：放射状切开＋序贯扩张。
复杂型（软骨受累）：通常需要支架。

异物要点：尽可能牢固地夹持异物，并与硬镜一起整块取出；若取出途中遗失，应检查口咽部。

核心概念

适应证与禁忌证

常见适应证：恶性或良性中央气道梗阻、大咯血、复杂异物取出、狭窄扩张、支架置入，以及辅助热消融或冷消融治疗。硬镜常作为多种联合干预的平台，例如扩张＋支架、激光／APC＋机械减瘤。

禁忌证：

  • 绝对禁忌证：颈椎不稳定。
  • 相对禁忌证：既往颈椎融合、血流动力学不稳定、严重低氧血症、严重凝血功能障碍／血小板减少、术者经验不足。

何时优先选择硬镜而非软镜？气管病变、可致窒息的异物、大量出血，以及中央气道梗阻所致急性呼吸衰竭。硬镜可提供更可靠的气道控制、通气以及大口径吸引和器械操作。

术前评估

气道、影像和病变定位：明确梗阻模式（腔内型、外压型或混合型）以及远端气道是否通畅，以规划减瘤和支架治疗。

麻醉与通气计划：充分预氧合；与麻醉团队确认TIVA或其他方案；依据热治疗需求和器械占据管腔的程度，在自主－辅助通气和喷射通气之间选择。

风险分层：登记研究显示，ASA分级和体能状态（ECOG/Zubrod）与并发症及30天死亡率相关。

设备与设置

硬质支气管镜：由不锈钢制成，直形、远端带斜口，并可有远端侧孔（支气管镜约40 cm，气管镜约30 cm）。常见外径约9–14 mm；镜管常以颜色编码；近端设有多个通气和器械接口。

观察系统：可使用直视望远镜或摄像系统；软质支气管镜常经硬镜管腔置入，用于远端检查、气道清理和辅助治疗。

平台：常用系统提供可互换镜管、通用镜头连接头，以及保留较大吸引和器械通道的一体化半软式内镜。

逐步技术／操作核查表

1. 硬镜插管（核心步骤）

  • 体位：头部轻度后伸（“嗅闻位”）；用手指或牙垫保护牙齿。
  • 置入：沿中线置入，斜口朝前；越过会厌下方后旋转90°，通过声门进入上段气管。
  • 进入主支气管：若要进入一侧主支气管，将患者头部转向对侧肩部。
  • 镜管尺寸：必要时先置入较大气管镜；随后可经其置入较小镜管，无需重新插管。
  • 评估：经硬镜置入软镜，完成远端评估和清理。
  • 胜任力（RIGID-TASC）：使用标准化核查表评估硬镜基本技能。受训者通常在约5–24例硬镜操作后达到胜任水平，中位数约15例。

2. 肿瘤减瘤（腔内型或混合型）

  1. 凝固／去血管化。
  2. 机械削切：使用远端斜口进行“螺旋推进／削芯”。
  3. 凝固基底。
  4. 支架：存在残余外压、气道不稳定或高复发风险时置入支架。

3. 异物取出

  • 圆滑异物选择平滑钳；尖锐或不规则异物选择鳄口钳。
  • 将硬镜、异物钳和异物一起整块取出，以防异物脱落。
  • 若取出途中异物遗失，重新插管前先检查口咽部和喉部。

故障处理与术中管理

大咯血

处理：使用硬镜插管，通气并保护对侧肺。

止血：用镜管本身压迫；根据情况使用冰盐水、APC、激光光凝或电灼。

危重狭窄／难以进入

处理：使用较小的儿科镜管、球囊，或先用软镜引导通过初始狭窄通道；随后序贯扩张。

通气方式选择

自主／辅助通气：闭合系统，需要填塞漏气处。可进行PEEP和压力监测，但器械占据管腔时可能发生低氧。

喷射通气：可腾出管腔空间，并在热治疗前迅速降低FiO₂。但无法测量气道压力，因此医源性气胸风险增加。

术后护理与随访

预期效果：中央气道再通后症状通常迅速缓解。减瘤后的获益一般维持2–3个月；置入支架后约维持4个月，如肿瘤系统治疗有效则可更久。

监测：对于经内镜治疗的良性肿瘤，应安排随访支气管镜，因为虽少见，仍可能复发或发生恶变。

并发症：预防、识别与处理

  • 发生率：大型病例系列／登记研究中，总并发症率约3.9%，操作死亡率约0.4%–0.5%。
  • 类型：口咽或牙齿损伤、气管后膜部撕裂、低氧／高碳酸血症、出血、气胸、心律失常。
  • 危险因素：紧急／急诊操作、ASA分级＞3、再次操作，以及中度镇静（相较于全身麻醉）。
  • 30天死亡相关因素：ASA分级＞3、ECOG＞1、腔内型／混合型梗阻及支架置入，尤其是Y形支架；这些因素往往反映较高疾病负荷。

特殊人群／情境

气管食管瘘（TEF）：评估体积较大的食管肿瘤是否压迫气道。支架置入顺序需个体化；优化食管支架后瘘仍持续时，常需双支架（气道＋食管）。

插管后／气管切开后良性狭窄：区分单纯型与复杂型，可决定仅扩张还是置入支架以稳定软骨支架结构。

术后／肺移植吻合口：高度紧窄的狭窄可能需要先使用儿科镜管或球囊。

证据与结局

有效性：多中心登记数据（＞900例患者、＞1,100次操作）显示技术成功率约93%。术前Borg呼吸困难评分越高，改善越明显；仅肺叶支气管梗阻者改善较少。

成功预测因素：支气管腔内病变和支架置入（提高成功率）；ASA分级＞3、肾衰竭、左主支气管病变和TEF（降低成功率）。

安全性与麻醉：单中心病例系列支持在高风险人群中采用TIVA联合自主－辅助通气的安全性；操作时间是可干预的30天死亡预测因素。

病例与应用学习

病例1——大咯血与气道保护

一名64岁鳞状细胞癌患者出现300 mL咯血和低氧血症。下一步最佳处理是什么？

A．在中度镇静下经软镜大量灌注冰盐水
B．用气管导管选择性插管，等待介入放射栓塞
C．在全身麻醉下行硬质支气管镜术，保护气道并压迫止血，随后局部止血
D．雾化氨甲环酸并观察
E．立即开胸

答案：C。硬镜可实现气道控制、吸引、压迫止血并应用多种局部止血方式。

病例2——混合型MCAO

一名58岁患者有呼吸困难，CT显示右主支气管肿块并伴外压。最佳内镜处理顺序是什么？

A．仅球囊扩张
B．去血管化 → 机械削切 → 凝固基底 → 支架
C．仅激光
D．先置入支架，再经支架使用激光
E．仅光动力治疗

答案：B。混合型梗阻既需去除腔内成分，也需支架处理外压和气道不稳定。

病例3——插管后良性狭窄

一名36岁患者出现短段气管狭窄，软骨完整。首选哪种方法？

A．首选硅酮支架
B．三个方向放射状切开后序贯扩张；若软骨完整（单纯型狭窄），无需支架
C．仅电灼
D．仅用硬镜斜口机械削切
E．立即气管切除

答案：B。单纯型（黏膜性）狭窄常可经放射状切开＋扩张改善；复杂型（软骨受累）通常需要支架。

题库（选择题）

  1. 下列哪项是硬质支气管镜术的绝对禁忌证？
    A．既往接受过硬镜操作
    B．既往颈椎融合
    C．颈椎不稳定
    D．大咯血
    E．ASA III级
    答案：C。颈椎不稳定是绝对禁忌证。
  2. 硬镜插管时，下列哪一操作正确？
    A．通过声门时始终使斜口与声带平行
    B．斜口越过会厌下方后旋转90°通过声门
    C．进入目标主支气管时将头转向同侧
    D．插管时用左手持镜
    E．单次尝试可超过120秒
    答案：B。识别解剖标志并正确旋转是安全硬镜插管的核心。
  3. 哪种通气方式最有利于热治疗前迅速降低FiO₂？
    A．自主－辅助通气
    B．喷射通气
    C．高频振荡通气
    D．无呼吸氧合
    E．负压通气
    答案：B。喷射通气可迅速降低FiO₂，但无法监测压力。
  4. 登记研究中，哪项因素与较高技术成功率相关？
    A．仅肺叶支气管梗阻
    B．ASA分级＞3
    C．支气管腔内病变和／或支架置入
    D．存在TEF
    E．肾衰竭
    答案：C。两者均与成功率提高相关。
  5. 使用硬镜处理腔内型肿瘤的减瘤顺序是：
    A．削切 → 凝固基底 → 去血管化
    B．去血管化 → 削切 → 凝固基底
    C．扩张 → 支架 → 激光
    D．先支架 → 经支架激光
    E．仅冷冻取出
    答案：B。该顺序可减少出血并高效恢复管腔。
  6. 纯外压型梗阻且无腔内肿瘤时，最合适的一线治疗是：
    A．激光减瘤
    B．冷冻治疗
    C．扩张后置入支架
    D．光动力治疗
    E．观察
    答案：C。该方案直接处理机械性压迫。
  7. 硬镜操作中喷射通气的一项安全性缺点是：
    A．FiO₂下降缓慢
    B．无法使用热治疗
    C．无法监测气道压力，增加气胸风险
    D．难以通过器械
    E．PEEP过高
    答案：C。这是喷射通气的关键权衡。
  8. 登记研究中，哪项因素与并发症相关？
    A．全身麻醉
    B．中度镇静
    C．ASA I–II级
    D．择期门诊操作
    E．无既往支气管镜史
    答案：B。中度镇静与较高并发症率相关。
  9. 治疗性支气管镜术后30天死亡率与以下因素均相关，除外：
    A．ASA分级＞3
    B．ECOG＞1
    C．腔内型或混合型梗阻
    D．仅肺叶支气管梗阻
    E．置入Y形支架
    答案：D。仅肺叶病变通常不具有同等高风险特征。
  10. 取出嵌顿于支气管内的圆形异物，最佳做法是：
    A．用鳄口钳分块取出
    B．用平滑钳夹持，并将硬镜＋钳＋异物整块取出
    C．仅用冷冻探头
    D．激光碎裂后吸出
    E．仅经软镜使用网篮
    答案：B。可最大限度减少异物脱落或再次误吸。
  11. 插管后良性狭窄若有软骨受累（复杂型），硬镜治疗计划应包括：
    A．仅序贯扩张
    B．仅激光
    C．扩张＋支架以稳定气道
    D．观察
    E．外照射放疗
    答案：C。通常需要支架稳定气道。
  12. 关于硬镜麻醉，下列哪项最准确？
    A．因系统闭合，首选吸入麻醉
    B．首选TIVA；硬镜为开放系统，吸入麻醉时漏气和环境污染明显
    C．中度镇静与TIVA结局相同
    D．无需预氧合
    E．挥发性麻醉药比喷射通气更快降低FiO₂
    答案：B。TIVA最常用；中度镇静与更多并发症相关。

争议、实践差异与演进中的证据

  • TEF支架顺序：先置气道支架、食管支架或双支架需个体化。许多中心先置食管支架；若气道已受压，则应先置气道支架；瘘持续时常需双支架。
  • 通气选择：不同中心在自主－辅助通气和喷射通气之间存在差异。两者均可接受；喷射通气降低FiO₂更快，但不能监测压力。
  • 镇静策略：硬镜下中度镇静与更高并发症率相关，但在少数情境仍可能采用；TIVA占主导地位。

要点核查表

  • 确认适应证并排除绝对禁忌证（颈椎不稳定）。
  • 团队统一麻醉／通气方案（优先TIVA；自主－辅助或喷射通气按病例选择）。
  • 准备完整硬镜器械：多种镜管尺寸、望远镜／摄像系统、凝固装置、冷冻设备、扩张器、支架和吸引。
  • 插管顺序：沿中线、斜口朝前、越过会厌下方、旋转90°通过声门；进入主支气管时头转向对侧。
  • 腔内型肿瘤：去血管化 → 削切 → 凝固基底；热治疗时控制FiO₂。
  • 外压型／混合型：扩张并置入支架以维持稳定。
  • 大咯血：用硬镜控制气道、压迫和局部止血。
  • 异物取出：根据形状选择钳具；整块取出。
  • 良性狭窄：区分单纯型与复杂型；软骨受累时置入支架。
  • 预判并发症；避免中度镇静；识别高风险特征（急诊病例、ASA＞3、体能状态差）。
