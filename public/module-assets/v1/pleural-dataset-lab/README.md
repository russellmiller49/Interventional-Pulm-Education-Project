# Pleural Dataset Lab Raw Snapshot

This folder contains a small raw-pixel snapshot copied from public CC BY 4.0 lung ultrasound datasets for the pleural dataset source lab.

Sources:

- Mendeley Data: `A Dataset of Lung Ultrasound Images for Automated AI-based Lung Disease Classification`, V2, DOI `10.17632/hb3p34ytvx.2`.
- figshare: `Lung Ultrasound Dataset`, DOI `10.6084/m9.figshare.30093577.v1`.

Scope:

- The embedded files are unmodified raw image files from the downloaded archives.
- The app uses selected source labels, safe metadata fields, and derived teaching-use labels for education, attribution, and reviewer audit.
- The full archives remain case-by-case audit targets before broader public embedding.
- Figshare workbook names, narrative descriptions, and pathology free text are not copied into app metadata.
- Mendeley metadata was audited from `metadata.xlsx`; free-text comments and patient fields are not copied into app metadata.
