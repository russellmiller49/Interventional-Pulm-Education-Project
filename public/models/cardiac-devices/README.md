# Cardiac device runtime assets

Compact teaching assets generated by
`scripts/cardiac-assets/build-runtime-assets.py` from the shared cardiac rig.

## Runtime set

- `heart-great-vessels.glb`: project-authored open anterior aortic and pulmonary-artery lumen.
- `iabp-aorta-cutaway.glb`: project-authored arch-to-iliac cutaway with renal landmarks.
- `iabp-balloon.glb`: project-authored neutral catheter/balloon with an `Inflated` morph target.
- `impella-cp.glb`, `impella-55.glb`, and `impella-rp.glb`: optimized derivatives of the
  project-supplied authoring models. CP is the active MCS simulation model; 5.5 and RP are
  anatomy-only comparisons.
- `lvad.glb`: decimated pump/inflow-hardware derivative of the supplied LVAD authoring model. The
  source model's oversized fixed graft is omitted; the module builds a slimmer graft on the shared
  apical-pump-to-ascending-aorta rig.

All assets use named landmark/anchor nodes, local Draco compression, and the budgets recorded in
`asset-manifest.json`. The raw source GLBs remain under the ignored `3D assets/` authoring tree and
are not served by the application.

## Safety and provenance boundary

These are educational facsimiles, not sizing, catheter-depth, fluoroscopy, implantation, or
patient-specific planning models. Manufacturer instructions and local clinical policy remain
authoritative. Redistribution of supplied-model derivatives remains gated by the
`pending-clinical-and-rights-review` status in the runtime manifest.
