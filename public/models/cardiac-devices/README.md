# Cardiac device runtime assets

Compact teaching assets generated by
`scripts/cardiac-assets/build-runtime-assets.py` from the shared cardiac rig.

## Runtime set

- `heart-great-vessels.glb`: project-authored open anterior aortic and pulmonary-artery lumen.
- `iabp-aorta-cutaway.glb`: project-authored arch-to-iliac cutaway with renal landmarks.
- `iabp-balloon.glb`: project-authored neutral catheter/balloon with an `Inflated` morph target.
- `impella-cp-v1.glb`, `impella-55-v1.glb`, and `impella-rp-v1.glb`: project-authored procedural
  teaching facsimiles rebuilt at the CT heart's `0.024 web unit/mm` scale. The application loads
  these versioned URLs so older cached device bytes cannot replace this revision. The corresponding
  filenames without `-v1` remain byte-identical compatibility aliases only; bump the filename
  version, manifest URLs, CT registrations, and shared rig together for a visibly changed revision.
  These facsimiles replace the prior monolithic texture-atlas derivatives with named blue
  polyurethane cannula, red inlet/outlet cage, silver motor/marker, and dark proximal-shaft
  components. CP is 151 mm nominal invasive length, 5.5 is 114 mm, and RP is approximately 238 mm;
  exact educational anchor coordinates and diameter facts are recorded in `asset-manifest.json`.
- `lvad.glb`: decimated pump/inflow-hardware derivative of the supplied LVAD authoring model. The
  source model's oversized fixed graft is omitted; the module builds a slimmer graft on the shared
  apical-pump-to-ascending-aorta rig.

All assets use named landmark/anchor nodes, local Draco compression, and the budgets recorded in
`asset-manifest.json`. The procedural Impella assets contain no texture images. Their shared node
contract is intentionally component-level: `DistalPigtail` or `DistalTip`, `InletCage`,
`ReinforcedCannula`, `ReinforcementSpiral`, `AorticAnnulusMarker` where applicable, `OutletCage`,
`MotorHousing`, and `ProximalShaft`.

CP and 5.5 use the LV inlet center as local origin; RP uses the pulmonary-artery outlet center. In
all three assets, local `+Y` points distally. CP exports inlet, aortic-annulus, outlet, pigtail-tip,
and proximal-shaft anchors. 5.5 exports inlet, aortic-annulus, outlet, distal-tip, and
proximal-shaft anchors. RP exports PA outlet, IVC inlet, motor-center, pigtail-tip, and
proximal-shaft anchors; its registered inlet-to-outlet span is 205 mm, while the approximately
238 mm value describes the complete invasive portion. The raw supplied GLBs remain under the
ignored `3D assets/` authoring tree for provenance comparison and are not served by the application.

## Safety and provenance boundary

These are educational facsimiles, not sizing, catheter-depth, fluoroscopy, implantation, or
patient-specific planning models. Manufacturer instructions and local clinical policy remain
authoritative. Redistribution of supplied-model derivatives remains gated by the
`pending-clinical-and-rights-review` status in the runtime manifest.

Only the aortic cusps are complete segmented valve morphology in the shared heart. Mitral,
tricuspid, and pulmonic locations are route/orifice proxies only; none of these device assets
upgrades those proxy locations into leaflet morphology.
