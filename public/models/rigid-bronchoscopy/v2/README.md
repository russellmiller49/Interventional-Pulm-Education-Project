# Rigid bronchoscopy v2 assets

This directory is generated by `scripts/rigid-bronchoscopy/build-v2-assets.py`.
Do not edit its GLBs by hand or address them with unhashed filenames.

`asset-manifest.json` is the runtime contract. It maps stable asset IDs to
content-hashed GLBs and records units, bounds, PBR/mesh statistics, provenance,
estimated fields, EFER port/tool anchors, cap states, and four clearance-checked
procedural poses. All GLBs are meter-native; the lab applies the manifest's one
shared presentation scale of 9 world units per metre (0.009 per millimetre).

The anatomy assets are purpose-built, public-safe educational geometry containing
only the trachea, carina, and bilateral main bronchi. They are not patient-derived.
The hose, missing-cap, and stent-introducer assets are explicitly marked teaching
proxies. Manufacturer-published facts and estimated geometry remain separate in
the manifest.

Regenerate and validate from the repository root:

```bash
python3 scripts/rigid-bronchoscopy/build-v2-assets.py
python3 scripts/rigid-bronchoscopy/validate-v2-assets.py
/Applications/Blender.app/Contents/MacOS/Blender --background \
  --python scripts/rigid-bronchoscopy/validate-v2-blender-import.py -- \
  public/models/rigid-bronchoscopy/v2/asset-manifest.json \
  public/models/rigid-bronchoscopy/v2/blender-import-validation.json
```

The JSON validation reports are the tracked results of the last complete mesh,
manifest, and clean-Blender-import validation.
These assets are for education only, not manufacturing CAD, patient-specific
planning, procedural guidance, or a substitute for current instructions for use
and supervised clinical training.
