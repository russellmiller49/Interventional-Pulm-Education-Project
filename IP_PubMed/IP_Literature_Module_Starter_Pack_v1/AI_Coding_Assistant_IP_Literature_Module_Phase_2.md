# Follow-on AI Coding Assistant Prompt

## IP Literature Explorer — Phase 2: AI relevance and multi-label classification

Use this prompt only after the Phase 1 NBIB importer, Supabase schema, admin review queue, and lexical search are working with the real corpus.

### Objective

Add a provider-neutral, reproducible AI classification pipeline that decides whether each article is relevant to interventional pulmonology and suggests multiple taxonomy labels. Human review remains authoritative.

### Mandatory constraints

- Inspect and preserve all Phase 1 schema, audit, and authorization patterns.
- Do not overwrite manual relevance or topic decisions.
- Do not automatically hide or permanently exclude AI-negative records during initial validation.
- Do not classify based on journal name alone.
- Use only supplied bibliographic metadata.
- Validate all model output with Zod.
- Persist provider, model, prompt version, taxonomy version, input hash, timestamps, and validated output.
- Treat source query IDs only as weak hints.
- Use bounded concurrency, retries, resume behavior, and dry-run mode.
- No SQL generated by the model.
- No article summaries or medical conclusions in this phase.

### Deliverables

1. `LiteratureClassifier` server-only interface.
2. Versioned prompt stored as code/config.
3. Zod schema for relevance, reason codes, topics, facets, study design, publication class, evidence terms, and uncertainty.
4. Batch classification command with filters, limits, concurrency, dry-run, and resume.
5. Storage of each classifier run as a versioned suggestion rather than destructive overwrite.
6. Admin comparison of rule, query, AI, and human labels.
7. Gold-standard export/import workflow.
8. Metrics report with relevance precision/recall and per-topic performance.
9. False-negative audit workflow.
10. Documentation of thresholds; automation remains disabled until explicitly approved.

### Initial classifier distinctions that must be tested

- Convex EBUS vs radial EBUS.
- EBUS staging vs diagnostic sampling.
- Robotic bronchoscopy vs electromagnetic navigation.
- Cone-beam CT vs conventional fluoroscopy.
- BLVR endobronchial valves vs persistent-air-leak valves.
- ILD cryobiopsy vs peripheral-lesion, mediastinal, and endobronchial cryobiopsy.
- Airway stenting vs vascular/esophageal stenting.
- Medical thoracoscopy/pleuroscopy vs surgical VATS.
- Advanced therapeutic bronchoscopy vs routine BAL/diagnostic bronchoscopy.
- Bronchoscopic tumor ablation vs surgical or percutaneous ablation.

### Initial release rule

All AI outputs are suggestions. An article enters the public collection only when the established workflow marks it `included` and `published`. Do not change that rule during this phase.

### Completion report

Provide classifier architecture, exact prompt/schema versions, batch commands, validation sample composition, metrics, false-negative examples, cost/throughput observations, and the recommended thresholds without enabling them automatically.
