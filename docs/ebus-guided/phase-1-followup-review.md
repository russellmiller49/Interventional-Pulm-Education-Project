## Instructor walkthrough

**Station 7:** open `section=station-seven`. Read Orientation and Worked example; expand neighboring anatomy and try separate rotation/flexion demonstrations. In Guided activity, identify/check the carina and both main bronchi. Wrong selections give spatial hints and require another selection. Slowly cross the target from one edge to the other, pausing for images; return to a visible section. Repeat from the other assisted bronchial start. Interpret the held ultrasound and review Explain. In Another situation, identify the landmarks and acquire a new sweep at the changed left-bronchial position, then hold and interpret it.

**4R:** open `section=right-paratracheal`. Inspect the worked anatomy, then identify/check azygos, SVC and left brachiocephalic vein in the unnamed view. Cross the target gradually and return to a visible section. After Observe/Explain, repeat the task at the changed position and justify the compartment from airway/venous relationships. There is no learner 4R/10R contrast or claim that a node outlines a complete compartment.

For repeatable software review, the browser helper moves from +90 to −90 in 10-degree increments, waits for each matching frame, then returns to a visible section. These describe this authored test only; learners can use smaller increments. Observer orbit never supplies acquisition credit.
