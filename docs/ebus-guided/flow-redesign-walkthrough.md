# Instructor walkthrough

Use the unlisted `/en/ebus-guided` course on the local production preview at `http://127.0.0.1:3157`. Start with a fresh browser context for a new-learner demonstration. Existing course completions and first responses remain historical; restart does not erase them.

## Course entry and teaching

1. Open Overview, then Start course. The course map has seven chapters and 26 stable lesson links. Measurement phantoms precede capture.
2. In **Define the clinical question**, read the request, explanation and worked case before matching the information needs. Submit each decision and inspect its reasoning. A diagnosis does not imply that staging or ancillary testing is complete.
3. Use Course outline to navigate, Back to review an earlier task, Help for current instructions, and Exit lesson to return to the course. Back pauses the active workbench. The next task scrolls into view. An unfinished lesson restarts on reload; the separate case draft can restore.

## Scope, plane and contact

1. Open `scope-orientation`. Identify the distal transducer in the physical explanation. Try the demonstration controls; they do not complete the learner task.
2. Start the separate acquisition. Check the transducer landmark, then rotate through the target in small increments, waiting for each image. Orbit changes the observer camera and earns no acquisition credit.
3. Hold the acquisition. Interpret the same grayscale pixels before revealing the explanation. Changing width or reviewing earlier teaching must not reset the pose or create a new image.
4. In `acoustic-contact`, compare initial/current tip-wall views and actual ultrasound acquisitions. Use small tip-flexion changes until the window returns. The initial comparison waits for a real frame before movement opens. The contact index does not measure pressure, force or balloon volume.
5. Follow the companion link to `contact-cutaway-model` to examine the supported air-gap, direct, balloon, bubble and shadow states. Its model actions are still required; the companion is part of the same conceptual course sequence.

5. The 4L and hilar/interlobar lessons retain their explicitly bounded regional/reference activities. They do not acquire newly validated multi-case windows.

## Recorded images and capture

1. `image-depth` starts with paused recorded examples. Compare the deep reference with the selected 3–4 cm example. The previous image stays fixed until **Keep this image for comparison** is explicitly selected.
2. In `gain-contrast`, change one control at a time. The previous pixels remain visible while the selected lookup example changes. Combined arbitrary image synthesis is not claimed.
3. In `doppler`, compare grayscale with the existing color recording and interpret detected flow. Absent color does not establish an avascular or safe path.
4. Complete the analytic `measurement-phantoms` sweeps and required short-axis/border exercise. Its calibrated phantom dimensions do not transfer to clinical recordings.
5. In `capture`, freeze, place two deliberate calipers and save. Hold the actual captured frame and inspect the compact capture record. This verifies control use and retained pixels; clinical border accuracy, station identity and a calibrated size are not scored.
6. Play a clip explicitly, then review an earlier task and return. Playback should remain paused until requested again. Reload starts an unfinished acquisition over; it does not autoplay or restore stale image guidance.

## Needle and specimen reasoning

1. In `needle-safety`, connect each action to the current image and patient situation. Open `needle-assembly-model` for the linked sheath/needle/stylet/outlet states.
2. In the model, try advancement with a frozen image, a lost tip and resistance. These actions must be blocked. Exposed-tip removal must also be rejected. The model requires the recovery/retraction sequence and retains its generic device limitation.
3. Open `systematic-staging` and plan the written **Left lung primary** case. Select the relevant stations and assign case-relative categories. Two nodes at 4R still occupy one station. Planning marks no target sampled or normal.
4. Continue in `adequacy-rose`: the case supplies distinct blood-only material, provisional ROSE information, a representative station-7 sample, and pending final/ancillary results. Reconcile each endpoint, including the branch without ROSE.
5. In `specimen-triage`, preserve each specimen label. Use supplied processing instructions; choose laboratory clarification for the missing ancillary requirements. The case does not prescribe a universal medium, quantity or pass count.
6. In `results-reporting`, reconcile each source entry with visualization and sampling fields. Keep the inadequate 4L window and unexamined 11L target with their reasons. Build the report from supported statements, retaining the nonrepresentative sample and pending results. These findings were supplied written history, not generated by the model or by visiting lessons.

## Practice, failure and recovery

- Practice defaults to coaching after each response. Select Independent practice for delayed ordinary correctness; unsafe choices still require immediate revision. Coached first responses have distinct versioned keys. Final assessment retains eight cases, existing eligibility and no new passing threshold.
- At phone widths, reading and recorded-image activities remain usable. Required WebGL/model work clearly remains incomplete until a supported viewport/device is available. A still reference does not earn acquisition credit.
- If a model or recording fails, the relevant activity remains blocked. Retry/restart creates fresh evidence. An actual iframe reboot invalidates the held image even if old metadata is replayed.
- Reload a partially completed case plan: compatible fields restore, with a historical-metadata notice. A content/geometry mismatch must produce an incompatible-draft notice; **Start a record for this version** archives the previous draft before a new one can be written.

This walkthrough is a technical/formative review guide. Faculty content approval, rights review, observed novice usability, supervised performance and educational effectiveness remain separate evaluations.
