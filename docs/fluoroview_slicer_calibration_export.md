# FluoroView 3D Slicer Calibration Export

Use this when Slicer shows the CT and airway model aligned but the FluoroView browser overlay does
not. The export captures the Slicer scene geometry that FluoroView needs to reconcile coordinate
systems and projection math.

## What To Export

The most useful artifact is:

```text
slicer_calibration_bundle.json
```

It includes:

- CT volume `IJKToRAS` and `RASToIJK` matrices
- CT volume spacing, origin, dimensions, and RAS bounds
- model parent transform matrices and RAS bounds
- segmentation parent transform matrices, segment RAS bounds, and optional sampled surface points
- markup/centerline control points in world RAS
- transform nodes
- 3D camera position, focal point, view-up, and projection mode
- slice view `SliceToRAS` and `XYToRAS` matrices

Slicer uses RAS coordinates. FluoroView uses LPS coordinates, so points convert as:

```text
LPS = [-RAS_R, -RAS_A, RAS_S]
```

## How To Run

Open the aligned CT/model scene in 3D Slicer. Set the 3D view to the projection you trust.

Then run this from Slicer's Python Interactor, adjusting the output path:

```python
import sys
sys.argv = [
    "export_slicer_calibration_bundle.py",
    "/Users/russellmiller/Desktop/fluoroview-slicer-calibration",
    "--screenshots",
    "--sample-model-points",
    "20",
]
exec(open("/Users/russellmiller/Projects/Interventional-Pulm-Education-Project/tools/fluoroview-pipeline/scripts/export_slicer_calibration_bundle.py").read())
```

You can also run it from a terminal with Slicer:

```bash
/Applications/Slicer.app/Contents/MacOS/Slicer \
  --python-script /Users/russellmiller/Projects/Interventional-Pulm-Education-Project/tools/fluoroview-pipeline/scripts/export_slicer_calibration_bundle.py \
  /Users/russellmiller/Desktop/fluoroview-slicer-calibration \
  --screenshots \
  --sample-model-points 20
```

On Windows, use your Slicer executable path and a Windows or WSL-visible output folder:

```powershell
& "C:\Users\<YOU>\AppData\Local\NA-MIC\Slicer 5.8.1\Slicer.exe" `
  --python-script "C:\path\to\Interventional-Pulm-Education-Project\tools\fluoroview-pipeline\scripts\export_slicer_calibration_bundle.py" `
  "C:\Users\<YOU>\Desktop\fluoroview-slicer-calibration" `
  --screenshots `
  --sample-model-points 20
```

## What To Send Back

Send or copy back:

- `slicer_calibration_bundle.json`
- `slicer_screenshots_manifest.json`, if generated
- the screenshot PNGs generated by `--screenshots`

Also helpful if available:

- a saved Slicer scene bundle `.mrb` with only de-identified derived model/markup data
- a manually placed markup point named `FluoroView_Carina` at the carina in Slicer
- markup points for trachea top, right mainstem, left mainstem, and visible DRR/slice landmarks

Do not commit or send raw DICOM, raw NIfTI, NRRD segmentation volumes, STL, or OBJ source meshes.
