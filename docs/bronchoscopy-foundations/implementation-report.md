The implementation retains conventional explicit correct/unsafe outcome wording from the shared AnswerVerdict component. The source/item copy gate does not replace that shared, accessible outcome contract. No shared component was changed to customize this course's vocabulary.

Remaining review findings are explicit: the larynx junction exceeds its original geometric limit; every asset still needs the appropriate rights/anatomy review; all clinical items remain draft; local-policy links require owner/faculty decisions; optional E01–E04 and variants are not built. A generic practice target is not an abnormal finding image. Manual screen-reader testing, novice usability observation, hardware-wide performance testing and faculty examination of physical handling have not been claimed.

The current task boundary is a technically verified, unlisted core build and a reviewable PR. The [faculty packet](faculty-review-packet.md) specifies the remaining release decisions.
