# CRRT-FELLOW-04 — before/after copy sheet

This is a compact record of learner-visible wording changed in this batch. For strings rendered
from data, the shape is shown. "Class" uses the handoff's classifications:

- **PF** — presentation fixed; clinical meaning unchanged.
- **F** — fixed.
- **NEW** — copy that did not exist before.

No answer ID, key, option text, case rule, source record or review status changed. Option-text
rewrites are proposals only (`CRRT-FELLOW-04-owner-proposals.md`).
