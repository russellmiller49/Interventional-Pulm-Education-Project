## The finding

The external report's MV finding 2 ("Nine evidence entries are unnamed", P2) named `casebook-source-1…8` and `supplied-casebook-2026` in `src/features/mechanical-ventilation/content/evidence.ts`. The v2 adjudication kept it as a source-clarity item: use the actual source material or classify authored examples honestly, and never invent an identity.

At base `905372be` the eight `casebook-source-N` records were generated from `sources[]` in `source-cases.v1.json`, as follows:

- **Titles:** each was titled `Casebook source N`.
- **Classes:** ids 6–8 were classed `educational-model` and the rest `clinical-reference`.
- **Limitation:** all eight shared one limitation.
- **Case set record:** `supplied-casebook-2026` said the case set was "supplied by the course author, July 2026", with pages 1–36.

The hub and case-activity `SourcesPanel` lists every non-manufacturer record, so all nine were visible to learners there. It labeled every `clinical-reference` record "Casebook clinical source", including the Tobin chapters and the Antonogiannaki review, which are not casebook sources. The three preprints were labeled "Educational model", the same label as this module's own simulation model.
