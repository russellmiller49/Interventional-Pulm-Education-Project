## 4. Observations per stop

Use one block per stop the learner opened. Keep the three kinds of note apart:

- **Observed** — what the learner did or said. Quote only with permission; otherwise paraphrase.
- **Interpretation** — what the facilitator thinks it means. Mark it as interpretation.
- **Proposed change** — a change to the module, not a comment on the learner.

Do not write whether an answer was correct, how many tries it took, or how much help was used. No tallies.
