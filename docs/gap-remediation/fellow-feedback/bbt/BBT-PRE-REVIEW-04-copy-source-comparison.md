# BBT-PRE-REVIEW-04 — learner wording before and after, with sources

Every substantive learner-facing change in this batch, with the source it reuses or derives from.
Short paths are under `src/features/bronchial-branch-tracing/` unless a full path is shown. "Held"
rows are proposals that were **not** implemented; they are listed separately at the end and are
not complete merely because they appear here.

No sentence below adds anatomy. Where a sentence is generated, it is generated from unchanged
source data (the checkpoint export `geometry/branch-decisions.json`, the target manifest
`public/branch-tracing/targets-v1/manifest.json`, or the native-v1 slice rule), and its source
qualifier is shown with it on screen.
