# ECMO-FELLOW-04 — before/after copy ledger

Companion to [ECMO-FELLOW-04-handoff.md](ECMO-FELLOW-04-handoff.md). One row per source ID with a
lane-04 component in `FEEDBACK_LEDGER.md` (51 rows), plus S14-1, which the batch brief lists and the
ledger assigns to lanes 01 + 02 + 05.

Prepared October 3, 2026 by Claude (AI implementation). **Not reviewed by a clinician, a
perfusionist or a device specialist.** The source rows come from
`CARDIOHELP_ECMO_learner_walkthrough.docx`, an AI-assisted browser walkthrough written in a
first-year-fellow persona; they are leads, not learner data and not clinical review.

**How to read it.**

- _Current-main baseline_ is what `origin/main` `9086f2af` rendered on a production build before
  any edit (the text of all 240 Learn steps and all 16 Practice and integrated cases was dumped from
  that build), or what the code held where the row is not a rendered string.
- _Prompt-04 residual_ is what was still wrong after Prompts 01–03 and PR #315.
- _Before_ / _After_ quote the learner-facing words. "—" means nothing was changed.
- Nothing in this batch changes physiology, an answer key, a threshold, persistence, a score or a
  gate. Where a sentence was false, the sentence changed.

**Dispositions (52 rows):** 23 repaired · 8 partly repaired · 3 contained · 14 already repaired by a
prior batch · 2 no change needed · 2 clinical/content hold · 0 not reproduced. The 14 "already
repaired" rows are not counted as Prompt-04 work.
