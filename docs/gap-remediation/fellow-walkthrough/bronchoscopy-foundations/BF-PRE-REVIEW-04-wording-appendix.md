# BF-PRE-REVIEW-04 — before/after wording, with where each word comes from

Every learner-facing string this batch changed or added, for text review. "Source of the words"
says what the new wording is drawn from; nothing here was written from clinical memory. Strings are
quoted as they render; `{…}` is filled from data at render.

**Not changed anywhere in this batch:** any question stem, option, key, rationale or explanation;
any dose, concentration, volume, threshold or medication statement; any anatomical claim; any
source record, source class, page locator or review flag; any section, step, item, block, goal or
control id. SUP-07 (local-anaesthetic dose guidance) was not touched.

Status of every row: **implemented, awaiting owner text review.** None is clinically approved.
