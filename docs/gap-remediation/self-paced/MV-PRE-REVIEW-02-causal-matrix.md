# MV-PRE-REVIEW-02 — causal matrix

Companion to `MV-PRE-REVIEW-02-handoff.md`. One row per modeled relationship this batch touched or
examined. **Classification** is one of the four the pack defines:

- **Physiology corrected** — a demonstrated implementation mismatch, repaired with a specification
  that already existed (in the casebook, or in the engine's own equations).
- **Observation labeling corrected** — the model may be unchanged; a value, readiness or provenance
  claim was false and now is not.
- **Misleading inference contained** — the model lacks the authority for the conclusion; every
  surface that drew it is stopped from drawing it, and the useful teaching is kept.
- **Decision still open** — a defensible repair needs a specification or owner decision nobody has
  provided. Named in the handoff's owner list; nothing here claims it is settled.

identical model time from the same start state (`scripts/critical-care/mv-causal-inventory.ts`),
Hamilton C6 profile, Practice experience, unless a row says otherwise. None is a clinical target.
