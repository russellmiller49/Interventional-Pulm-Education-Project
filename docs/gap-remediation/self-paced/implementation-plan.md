### MV-01 experiment specification

The external report's **13.1 → 0.9 cm H₂O over 120 seconds** is an externally reported observation at the historical baseline, not a G00 result or golden target. Its review-container driver is not in this repository. Recreate the experiment explicitly:

1. Resolve the exact MV-03 `short-machine-ti` branch, device, settings, patient, seed/attempt, priming behavior and clock. Clone the same initial state for each arm.
2. Run wait only, no-op FiO₂, changed FiO₂ without changed breath timing, and an intervention that changes **actual expiratory time**. A lower set rate is not a valid timing comparator if total patient-triggered rate stays fixed.
3. At startup and 5, 30, 60 and 120 simulated seconds record intrinsic PEEP; analytic and waveform trapped volume/recoil; peak/plateau with measured/estimated/invalid labels; delivered tidal volume; actual Ti/Te; total and set rate. Record every action and check that the intended control really changed.
4. Trace four-second initialization priming and `unmodeledIntrinsicPeepCmH2O` / residual reconciliation. Test double-counting and time confounding, not an assumed target number. Do not introduce a pressure floor or claim that a display estimate is a hold measurement.
5. Repair only an explicit implementation contradiction and regression-test matched controls. If intent remains unresolved, retain the reproduction and narrowly exclude the misleading example pending attributable faculty/RT modeling review. Continue unrelated reviewed teaching. Neither an ungraded label nor an engine test constitutes clinical approval.
