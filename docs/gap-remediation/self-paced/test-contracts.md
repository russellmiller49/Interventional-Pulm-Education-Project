# Test-contract migration ledger

G00 changes the active product contract, not the runtime tests. **No assertion was deleted, relaxed, skipped, or rewritten in G00.** The existing baseline and its counts are retained in [G00-handoff](G00-handoff.md). A passing legacy exam assertion is evidence of current implementation, not a release requirement under v2.

For each module conversion, record the exact changed assertion, its replacement, command/result, preserved invariants and implementation commit. Retain legacy read/validation tests when they protect historical records; do not exercise a new self-paced session through a graded writer simply to preserve an obsolete test.
