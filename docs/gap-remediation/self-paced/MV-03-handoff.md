## Safety explanations and runtime safety

The three new notes explain harm in the stated case: a higher rate and a higher alarm limit in the trapped-gas emergency, and a repeated rate increase before the first has settled. They are content only; no code reads `safety` or `unsafe`.

The prompt forbids turning an incorrect choice into a weighted error, so `scoreVentilationQuestions`, the last place `unsafe` changed an outcome, is removed. The runtime interlocks are separate and unchanged: case circuit prerequisites, pending device edits with native confirmation, holds, alarms, the MV-03 hold and the engine's critical-intervention errors.

## Review packet

[MV-03-review-packet.json](MV-03-review-packet.json) (content version `mv-03-2026-09-15`) was generated from the base and current content by a script kept with the evidence, so no wording was hand-copied. The generator refuses to run if any legacy-facing field changed.

- **Question items (10).** Each holds:
  - Its routes, disposition and concept.
  - The unchanged legacy fields.
  - Every changed field with previous and current wording, and the safety explanations.
  - Source locators (registered chapter, PDF page, section, and a finding: supports, partly supports, narrows, does not address, or conflicts), plus what was not checked and unresolved questions.
  - An empty reviewer decision.
- **Source identity items (9).** Each holds previous and current title, class, citation and limitation, the identity, the documents checked and the unresolved questions.
- **Related registry changes.** The six records that gained identity lines or chapter authors.

Its test enforces honesty only. A decision is either `NOT REVIEWED` with null fields, or has a named non-AI reviewer, role, date and version. Quoted current wording must equal the content, so any later wording change reopens review. Locators must be registered, explicitly unregistered, or `none`.
