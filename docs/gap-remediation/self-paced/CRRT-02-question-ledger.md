# CRRT-02 question and option ledger

Scope: **CRRT-05, CRRT-15 and CRRT-16 only.** Dispositions describe what the learner sees. Every
former record (option lists, unsafe-action and critical-error records, reassessment options,
dormant answer keys) stays in the runtime registry for case identity and history; none earns a
grade, and none of the retired records is rendered.

CRRT-01 had already replaced the five goal/mechanism/control/response/reassessment dropdowns with
a generic worked plan. CRRT-02 replaces that generic plan with a case-specific worked example
(`src/features/baxter-crrt/content/workedCaseExamples.ts`) and decides the remaining options below.
The full wording of every new item is in the [faculty packet](CRRT-02-faculty-packet.md).
