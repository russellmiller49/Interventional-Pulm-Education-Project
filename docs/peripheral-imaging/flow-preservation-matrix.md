# Section preservation matrix

Baseline: d209c800. The activity plan assigns every essential block exactly once and retains original objectives, prerequisite graph, questions, references and model boundaries. Nested technical details remain with their parent block; controls, troubleshooting and reconstruction references are available in the debrief. Model limitations stay visible during each task. Activity IDs do not replace historical question IDs.

@purpose: objective and prior-learning context. @worked: original scenario and reasoning. @summary: takeaways, retrieval answer, troubleshooting/control reference and relevant reconstruction detail. The matrix is derived from the same activity/lesson data that the host renders.
