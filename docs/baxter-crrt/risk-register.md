## 2. Highest-priority release blockers

The following block any public release:

1. Unknown local device market/configuration or program version.
2. Missing clinical evidence set and named clinical reviewers.
3. Missing device-trained review.
4. Any active citrate dosing without an approved local protocol.
5. Unresolved device/formula conflict used by active behavior.
6. Missing authentication, unlisted, and robots verification.
7. Progress or analytics privacy failure.
8. Accessibility failure involving alarms, controls, trends, mobile state, or reduced motion.
9. Any copyrighted/manual visual asset in the repository.
10. Any active critical error without independent review.
