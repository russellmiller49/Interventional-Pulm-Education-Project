## 2. Claim and behavior records

The relevant Phase 2 math records are materialized as strict TypeScript `SourceRecord` values.
Remaining implementation locations are later-phase targets. Reviewer is null for every record and
status is pending unless explicitly changed in a signed later revision.

This is a normalized registry. A complete SourceRecord is the join of:

- The source-registry row, which supplies source title/type/version, market/configuration, document
  limitation, and hash.
- The claim row, which supplies record ID, claim, page/section, implementation location, reviewer,
  and review status.
- The numeric metadata table below, when applicable.
- The conflict table, when a claim references a known ambiguity.

For nonnumeric claims, value and unit may be absent. Device profile/population is derived from the source
ID and claim family: PRISMAX-AW8035-RB maps to prismax-aw8035-2xx; PRISMAFLEX-G5036003-R05 maps to
prismaflex-g5036003-6xx; CLIN records apply to the synthetic adult ICU population; PROTO records
apply only to the named local protocol profile. Phase 2 materializes and validates every active or
explicitly disabled pure-math record; tests reject a missing required field.

## 4. Missing source work before pilot cases

The device audit is sufficient for the route/profile scaffold and Phase 2 pure engine. Phase 2
implements draft pure math only when the underlying source is captured and not disputed; every
result remains simulated/pending. Unsupported or disputed terms remain typed, disabled, or absent.
Before Phase 5 implements a pilot case, its clinical evidence must be captured and every
consequential claim mapped to a pending SourceRecord. Phase 5 may implement and test those cases only
inside the administrator-only authenticated draft with reviewStatus: pending. Phase 6 supplies the
post-implementation clinical/device review and gates any expanded pilot access or publication. The
Phase 5 evidence set must include:

- Current adult CRRT guidance and primary literature for indication, modality, delivered dose, and
  prescribed-versus-delivered teaching.
- Transparent sources for small-solute, acid-base, electrolyte, temperature, medication, nutrition,
  and liberation model assumptions.
- A local or explicitly versioned generic profile for non-citrate systemic anticoagulation concepts.
- A local citrate/calcium protocol before any actionable citrate pathway.
- Source-backed synthetic starting values, success conditions, accepted alternatives, unsafe actions,
  critical errors, and debrief claims for CRRT-04, CRRT-10, and CRRT-13.

Each added claim must receive a new stable row rather than being hidden in prose or a React
component.

- PRISMAFLEX-G5036003-R05 uses chapter pagination. Useful mappings include PDF p23 = 2:1,

## 6. Approval rule

A record may move from pending only when a named reviewer has checked the exact source revision,
page, implementation, tests, units, market/configuration, and learner-facing limitation. Any
consequential change resets that record to pending.
