## Coordinate and correspondence result

The clinical explorer uses the existing LPS-mm rendering frame throughout; the synthetic lesson adapter uses RAS-mm and an explicit LPS↔RAS involution. The two datasets are not co-rendered. No per-asset recentering is used. The patient-new mesh transform is verified against its current manifest and renderer: embedded node scale 0.001, then case scale 1000, then rotation X +90°. This maps original `[L,S,-P]` model vertices into `[L,P,S]`. The same CT origin and spacing position each plane and convert camera z to slice only when the learner requests alignment.

The browser comparison at the central airway was visually inspected: the tracheal bifurcation is visible in the intraluminal view and the CT plane passes through the corresponding exterior level. This is an engineering correspondence check. It is **not** a measured native-voxel registration study or physician approval of distal topology. Source-voxel error, ostial preservation, surface caps and named distal branches remain unreviewed.
