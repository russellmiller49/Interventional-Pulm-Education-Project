Some distal source centerline segments cross partial-volume or wall voxels. During export review, three sampling fractions were adjusted to use visible air points; the centerline was not silently corrected, source geometry was not mutated and continuous clinical registration was not declared. Inspect those middle-lobe intervals before adopting source points as reference annotations. The browser explicitly directs learners to the image evidence when their trace differs from the centerline.

Future scored checkpoint records need reviewer/date; case/content/asset/rubric versions; branch identities; continuous CT evidence and visibility limits; camera/mesh support; accepted alternatives; misconception feedback; allowed modes; source citations and exact derivative hash. Clinical scoring eligibility continues to fail closed in `content/types.ts` unless reviewed rights/deidentification, labels, poses and checkpoint IDs are provided.

Slicer was run in isolated headless processes. The existing user scene, source NRRD, source graph, source GLB and textbook file were not modified. No segmentation, dataset upload, clinical certification, deployment, publication or merge occurred.
