The final native case/transfer axe checks returned **zero violations in all 17 scenarios**. The VC/PC illustration’s browser check changes compliance, verifies unchanged axis labels, confirms VC retains its fixed 400 mL reference while PC delivery changes, and checks that the real patient storage remains unchanged. Numerical data/axes are not normalized independently. Normal-timing reference geometry also resizes without shrinking its labels.

**Real Chrome 200% zoom** was exercised through Chrome’s native zoom controls, not CSS scaling or a Playwright-only viewport substitute. Evidence: `zoom-200-reference.png`, `zoom-200-working.png`, `zoom-200-comparison.png`, `zoom-200-results.json`, plus the raw native UI zoom record. The latter remains outside Git because it contains surrounding browser UI context.
