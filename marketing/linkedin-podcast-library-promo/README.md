# LinkedIn Podcast Library Promo

Square LinkedIn-ready promo video for the InterventionalPulm.com IP Journal Review podcast library.

## Output

- `interventionalpulm-linkedin-podcast-library.mp4`
- `interventionalpulm-linkedin-podcast-library-poster.png`
- `public/videos/interventionalpulm-podcast-library-promo.mp4`
- `public/videos/interventionalpulm-podcast-library-promo-poster.png`

## Build

```bash
node marketing/linkedin-podcast-library-promo/build-linkedin-podcast-video.mjs
```

The script renders `1080x1080` frames at `30 fps` and encodes an H.264 MP4 with
ffmpeg. It creates a video-only file intended for a separately recorded voiceover.
